# THE ECHO — บทที่ 3: เงามืดนอกกรงฟาราเดย์

**[ECHO ARCHITECTURE LAB – EXECUTIVE LOUNGE – 11:15 น.]**

หลังจากถอดสลับสัญญาณออกจากสเปซจำลอง นิ้งและธันย์เดินกลับเข้ามาในโซนเลานจ์พักผ่อนอันหรูหราของแล็บ

บรรยากาศในเลานจ์เงียบสงบ ตกแต่งสไตล์มินิมอลด้วยโซฟาหนังแท้สีเบจและเคาน์เตอร์บาร์หินอ่อนสีดำ แสงแดดโปรยปรายลงมาจากช่องแสงหลังคาเพดานสูง

นิ้งเดินตรงไปยังเคาน์เตอร์บาร์แก้วด้วยท่าทางคล่องแคล่ว มือเรียวจับก้านชงกาแฟเอสเพรสโซ รินเอสเพรสโซร้อนเข้มข้นไม่มีน้ำตาลใส่ถ้วยเซรามิกทรงกระบอกสีกราไฟต์ขนาด 98x98 มิลลิเมตร พอดีเป๊ะ แล้วเดินถือยื่นส่งให้ธันย์อย่างนุ่มนวล *(ตัวเลข 98x98 ผุดขึ้นในหัวเธออย่างอัตโนมัติ — รายละเอียดจาก Mirror Fragment ที่ฝังไว้ลึกกว่าที่เธอรู้ตัว)*

ธันย์รับถ้วยกาแฟมาถือไว้ นัยน์ตาสีดำสนิทเลื่อนมองขนาดถ้วยกาแฟในมือ สลับกับใบหน้าเนียนของนิ้งด้วยสายตาราบเรียบแต่แฝงความสงสัยลึกซึ้ง

"ผมไม่เคยระบุรสนิยมกาแฟส่วนตัว หรือขนาดถ้วยทรงกระบอกนี้ไว้ในเอกสารสาธารณะ" ธันย์เอ่ยเสียงต่ำ เย็นชา "และผมไม่เคยสั่งกาแฟถ้วยนี้จากคุณ"

นิ้งหมุนตัวกลับไปรินชาขาวผสมเปปเปอร์มินต์ของเธอเอง ช้อนสายตามองเขาพร้อมรอยยิ้มป่วนยั่วเย้า "เดาค่ะ... หรือบางที สัญชาตญาณประสาทของฉันอาจจะจำได้ว่าคุณชอบดื่มอะไรยามเช้าโดยไม่ต้องเอ่ยปาก?"

ยังไม่ทันที่ธันย์จะได้เค้นถามต่อ เสียงสัญญาณเตือนภัยสีส้มบนคอนแทกต์เลนส์สแกนเนอร์ในดวงตาของเขาก็กะพริบแสงกระชั้นถี่!

*ติ๊ด! ติ๊ด! ติ๊ด!*

[SYSTEM ALERT: ZERO-DAY EXPLOIT DETECTED ON GUEST WI-FI]
[TARGET: NEURAL MAPPING DATASET]
[ORIGIN: AETHERIS CAPITAL EXTERNAL SERVER]

'ปอนด์' วิศวกรชีวประสาทผู้ช่วยมือขวาประจำแล็บ วิ่งหน้าตื่นเข้ามาในเลานจ์ เหงื่อเม็ดเล็กซึมตามขมับ

"บอสครับ! มีการเจาะสัญญาณข้ามผ่านไฟร์วอลล์เข้ามาจากวงเครือข่าย Local Guest Wi-Fi ครับ!" ปอนด์รายงานด้วยน้ำเสียงตื่นตระหนก "มีคนพยายามแฮกสกัดเอาไฟล์ Neural Mapping ที่เราเพิ่งสแกนจากคุณนิ้งเมื่อครู่!"

นิ้งสีหน้าเปลี่ยนเป็นนิ่งสงบในพริบตา นัยน์ตาคมกริบฉายแววรู้ทัน "ฝีมือ ดร.กานต์ Chief Scientist ของ Aetheris แน่นอนค่ะ... พวกนั้นเห็นฉันก้าวเข้าแล็บนี้ เลยรันไวรัสมาดักดูดโค้ดผ่านสัญญาณ guest"

ธันย์ไม่ได้ตื่นตระหนกแม้แต่น้อย ใบหน้าคมคายยังคงเย็นชาและสุขุม เขายกถ้วยกาแฟขึ้นจิบช้าๆ กลิ่นหอมเข้มข้นของเอสเพรสโซแตะที่ปลายลิ้น ก่อนจะขยับนิ้วรันคำสั่งบนแผงควบคุมกลางอากาศอย่างไม่รีบร้อน

"ปล่อยให้พวกมันดูดไป" ธันย์สั่งการเสียงนิ่ง

ธันย์หันมาหาปอนด์ เพิ่มเสียงต่ำ "และปอนด์ — ถ้ามีการ execute ไฟล์นั้นจากฝั่ง Aetheris เมื่อไหร่ก็ตาม ให้รัน Avalanche Protocol ทันที ไม่ต้องถามผมก่อน"

ปอนด์ชะงัก ตาโตเท่าไข่หาน "หา?! ปล่อยให้ดูดไฟล์สแกนสมองของคุณนิ้งเหรอครับบอส?!"

"ไฟล์ที่พวกมันกำลังดูดไปไม่ใช่โค้ดจริง" ธันย์อธิบายด้วยน้ำเสียงเฉียบขาด "ผมรันระบบสไลด์ข้อมูลเข้า Isolated Sandbox Port ไว้ตั้งแต่แรก ไฟล์ที่พวกมันจะได้ไปเป็นเพียง 'Honeypot Data' ข้อมูลประสาทขยะที่ถูกบีบอัด... ถ้าพวกมันพยายามเอาไฟล์นี้ไปคัดลอกหรือรันกับเซิร์ฟเวอร์หลักของ Aetheris อัลกอริทึม Data Avalanche จะทำงานทันที ข้อมูลขยะจะขยายตัวนับล้านเท่าถล่มระบบคลาวด์ของพวกมันจนพังพินาศภายในสามนาที"

นิ้งมองสถาปนิกหนุ่มตรงหน้าด้วยสายตาฉายประกายชื่นชมและความภาคภูมิใจอย่างปิดไม่มิด

"เฉียบคมสมเป็นคุณ..." นิ้งกระซิบเบาๆ ยิ้มหวานที่มุมปาก "ตั้งการ์ดป้องกันและวางดาบดักหลังไว้ตั้งแต่ปุ่มแรกที่สแกน"

ธันย์วางถ้วยกาแฟลงบนเคาน์เตอร์หินอ่อนเสียงดัง *กึ้ก* หันมาสบตานิ้งอย่างจริงจัง นัยน์ตากดดันเค้นถาม

"ตอนนี้บอกผมได้หรือยัง นิ้ง..." ธันย์เอ่ยเสียงต่ำ ทรงพลัง "...ทำไม Aetheris ถึงจ้องจะเล่นงานคุณ? และทำไมคดีความลิขสิทธิ์ของพวกนั้น ถึงสะท้อนลายเซ็นรหัสของผมในสมองคุณ?"

นิ้งถอนหายใจยาว วางถ้วยชาลงบนเคาน์เตอร์ นัยน์ตาสดใสมืดลงเล็กน้อยด้วยความหลังอันปวดร้าวในอดีต

"เพื่อตอบคำถามนั้น..." นิ้งสบตาเธอลึกซึ้ง "...คุณต้องยอมเปิด Memory Archive ในสมองของคุณ เพื่อย้อนกลับไปดูเรื่องราวเมื่อ 5 ปีก่อนค่ะ ธันย์"
