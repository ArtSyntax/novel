# THE ECHO — บทที่ 9: ห้องปิดตายและความแปรปรวนหัวใจ

**[ECHO ARCHITECTURE LAB – SESSION ISOLATION CORE – 01:30 น.]**

ด้วยความแค้นและจนมุม ดร.เดชา และคิณ ใช้คีย์การ์ดสิทธิ์เก่าของคิณที่ยังไม่ถูกถอนการเชื่อมต่อหลังงานประมูล แอบเจาะเข้าพอร์ตระบบท่อระบายอากาศด้านหลัง เพื่อลักลอบเปิดระบบล็อกฉุกเฉิน กักขังเซนและรินไว้ภายในห้อง Session Isolation Core ของ ECHO LAB!

[EMERGENCY LOCKDOWN ACTIVE]
[SYSTEM ISOLATION: 100% AIR-GAPPED]
[TIME DILATION FACTOR: 12.0x ACTIVE – 12 HOURS SIMULATED / 1 HOUR REAL-WORLD]

*Session Isolation Core ถูกออกแบบโดยเซนให้มีระบบ Neural Immersion ฝังอยู่ในผนังทุกด้าน เมื่อ Lockdown เต็มรูปแบบ ทั้งห้องจะซิงค์ระบบประสาทของผู้อยู่ภายในเข้าสู่ Time Dilation โดยอัตโนมัติ ราวกับ Neural Pod ขนาดยักษ์ที่ห่อหุ้มผู้ใช้งานทั้งคน*

ประตูเหล็กหนาสองชั้นปิดตายลงด้วยเสียงกระแทก *ตึง!* แผงควบคุมภายนอกถูกตัดสัญญาณ... พวกพวกเขาต้องติดอยู่ในห้องนี้เป็นเวลา 12 ชั่วโมงจำลอง (เท่ากับ 1 ชั่วโมงจริงในโลกภายนอก) จนกว่าเซิร์ฟเวอร์จะรันระบบ Auto-Reset

รินถอนหายใจ ยิ้มขี้เล่นมองสถาปนิกหนุ่มที่ยังคงรักษาใบหน้าเย็นชาและสุขุมเอาไว้ได้ เธอทรุดตัวลงนั่งบนขอบโต๊ะทำงานสแตนเลส ไขว่ห้างอย่างสบายอารมณ์

"ติดเกาะอยู่ในห้องปิดตายกับสถาปนิกไร้อารมณ์สิบสองชั่วโมง..." รินเอ่ยเย้า นัยน์ตาแพรวพราว "ถือเป็นฝันร้ายหรือฝันดีดีคะ คุณเซน?"

"ถือเป็นความยุ่งเหยิงทางสถิติที่หลีกเลี่ยงไม่ได้ครับ" เซนตอบเรียบๆ ขณะขยับนิ้วตรวจสอบแผงควบคุม Safety Valve นัยน์ตาจับจ้องเงาบันทึกระบบ

ทว่า... ระบบความปลอดภัยฉุกเฉินระบุการปลดล็อกประตูฉุกเฉินด้วย Biometric Recognition ชนิดพิเศษที่ไม่ใช่ Safety Valve มาตรฐานของแล็บ แต่เป็น Custom Override Key ที่ซ่อนอยู่

[SAFETY VALVE UNLOCK REQUIREMENT: COHERENT HRV + OXYTOCIN SYNC DETECTED]

เซนชะงักมองหน้าจอ... Biometric Key นี้ไม่ได้ใช้นิ้วมือหรือม่านตา แต่ต้องการ **ค่าความแปรปรวนของอัตราการเต้นหัวใจสอดคล้อง (Coherent HRV)** ผนวกกับ **ระดับสารออกซิโทซิน (Oxytocin)** ซึ่งเป็นสัญญาณชีพทางเคมีประสาทที่เกิดขึ้นเมื่อมนุษย์สองคนรู้สึกปลอดภัยและผูกพันลึกซึ้งในระดับสูงสุด!

ลึกๆ ในหัว เซนรู้ทันทีว่า Custom Override Key นี้เป็นฝีมือตัวเอง — เขาเขียนซ่อนมันไว้ในห้องทำงานส่วนตัวเมื่อ 3 ปีก่อน เพื่อรหัสผ่านฉุกเฉินสำหรับเขากับรินเพียงสองคน สัญชาตญาณบางส่วนส่งผ่านเข้ามาในโค้ดที่เขียนไว้โดยไม่รู้ตัว...

"น่าสนใจจัง..." รินยิ้มหวาน ก้าวลงจากโต๊ะเดินเข้าไปใกล้เซน กลิ่นหอมเปปเปอร์มินต์ผสมชาขาวลอยมาแตะจมูก "ระบบความปลอดภัยของคุณ ปลดล็อกด้วยความรักเหรอคะ?"

เซนจ้องมองดวงตาคู่สวยตรงหน้านิ่ง... ตรรกะอันแสนเนี้ยบเย็นชาของเขาพังทลายลงต่อความรู้สึกที่เอ่อล้นในอก สัญชาตญาณประสาทลึกๆ ที่เคยลืมเลือนไปตื่นขึ้นมาอย่างสมบูรณ์

เซนเปลี่ยนสภาพแวดล้อมในสเปซจำลองให้กลายเป็นทิวทัศน์หิมะสีขาวโพลนแสนโรแมนติก หิมะเกล็ดนุ่มโปรยปรายลงมาจากฟ้าเสมือนจริง สะท้อนแสงดาวระยิบระยับ

ร่างสูงสง่าขยับก้าวเข้าประชิด รวบตัวรินเข้ามาในอ้อมกอดแน่นหนา นิ้วเรียวยาวเชิดประคองใบหน้าเนียนหวานของเธอขึ้นสบสายตา นัยน์ตาสีดำสนิทฉายประกายลึกซึ้ง

"ผลการประมวลผลระบุว่า..." เซนกระซิบเสียงต่ำทรงเสน่หาลึกซึ้ง "...สถาปนิกคนนี้ ไม่ต้องการคูณสิบสองเท่าในโลกจำลองอีกต่อไปแล้วครับ"

เซนโน้มใบหน้าลงประทับจูบแสนอ่อนหวานและลึกซึ้งบนริมฝีปากนุ่มของริน กลางสเปซหิมะจำลองที่แสนงดงาม...

*วิ้ง...*

[BIOMETRIC RECOGNITION MATCHED: HEART SYNC HRV + OXYTOCIN DETECTED]
[SESSION ISOLATION CORE UNLOCKED]

สัญญาณไฟเปลี่ยนเป็นสีเขียว ประตู Isolation Core เปิดออกพร้อมกับอัตราการเต้นหัวใจของทั้งสองที่ประสานเป็นหนึ่งเดียวกันอย่างสมบูรณ์แบบ!
