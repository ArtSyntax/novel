# THE ECHO — บทที่ 9: ห้องปิดตายและความแปรปรวนหัวใจ

**[ECHO ARCHITECTURE LAB – SESSION ISOLATION CORE – 01:30 น.]**

ด้วยความแค้นและจนมุม ดร.กานต์ และภีม แอบส่งทีมรักษาความปลอดภัยเข้าลักลอบเปิดระบบล็อกฉุกเฉิน กักขังธันย์และนิ้งไว้ภายในห้อง Session Isolation Core ของ ECHO LAB!

[EMERGENCY LOCKDOWN ACTIVE]
[SYSTEM ISOLATION: 100% AIR-GAPPED]
[TIME DILATION FACTOR: 12.0x ACTIVE – 12 HOURS SIMULATED / 1 HOUR REAL-WORLD]

*Session Isolation Core ถูกออกแบบโดยธันย์ให้มีระบบ Neural Immersion ฝังอยู่ในผนังทุกด้าน เมื่อ Lockdown เต็มรูปแบบ ทั้งห้องจะซิงค์ระบบประสาทของผู้อยู่ภายในเข้าสู่ Time Dilation โดยอัตโนมัติ ราวกับ Neural Pod ขนาดยักษ์ที่ห่อหุ้มผู้ใช้งานทั้งคน*

ประตูเหล็กหนาสองชั้นปิดตายลงด้วยเสียงกระแทก *ตึง!* แผงควบคุมภายนอกถูกตัดสัญญาณ... พวกเขาต้องติดอยู่ในห้องนี้เป็นเวลา 12 ชั่วโมงจำลอง (เท่ากับ 1 ชั่วโมงจริงในโลกภายนอก) จนกว่าเซิร์ฟเวอร์จะรันระบบ Auto-Reset

นิ้งถอนหายใจ ยิ้มขี้เล่นมองสถาปนิกหนุ่มที่ยังคงรักษาใบหน้าเย็นชาและสุขุมเอาไว้ได้ เธอทรุดตัวลงนั่งบนขอบโต๊ะทำงานสแตนเลส ไขว่ห้างอย่างสบายอารมณ์

"ติดเกาะอยู่ในห้องปิดตายกับสถาปนิกไร้อารมณ์สิบสองชั่วโมง..." นิ้งเอ่ยเย้า นัยน์ตาแพรวพราว "ถือเป็นฝันร้ายหรือฝันดีดีคะ คุณธันย์?"

"ถือเป็นความยุ่งเหยิงทางสถิติที่หลีกเลี่ยงไม่ได้ครับ" ธันย์ตอบเรียบๆ ขณะขยับนิ้วตรวจสอบแผงควบคุม Safety Valve นัยน์ตาจับจ้องเงาบันทึกระบบ

ทว่า... ระบบความปลอดภัยฉุกเฉินระบุการปลดล็อกประตูฉุกเฉินด้วย Biometric Recognition ชนิดพิเศษที่ไม่เคยระบุในคู่มือ

[SAFETY VALVE UNLOCK REQUIREMENT: COHERENT HRV + OXYTOCIN SYNC DETECTED]

ธันย์ชะงักมองหน้าจอ... Biometric Key นี้ไม่ได้ใช้นิ้วมือหรือม่านตา แต่ต้องการ **ค่าความแปรปรวนของอัตราการเต้นหัวใจสอดคล้อง (Coherent HRV)** ผนวกกับ **ระดับสารออกซิโทซิน (Oxytocin)** ซึ่งเป็นสัญญาณชีพทางเคมีประสาทที่เกิดขึ้นเมื่อมนุษย์สองคนรู้สึกปลอดภัยและผูกพันลึกซึ้งในระดับสูงสุด!

ลึกๆ ในหัว ธันย์รู้ทันทีว่า Biometric Key นี้เป็นฝีมือตัวเอง — เขาเขียนมันไว้เมื่อ 3 ปีก่อน ก่อนที่ความทรงจำจะถูกลบ สัญชาติญาณบางส่วนส่งผ่านเข้ามาในโค้ดที่เขียนไว้โดยไม่รู้ตัว...

"น่าสนใจจัง..." นิ้งยิ้มหวาน ก้าวลงจากโต๊ะเดินเข้าไปใกล้ธันย์ กลิ่นหอมเปปเปอร์มินต์ผสมชาขาวลอยมาแตะจมูก "ระบบความปลอดภัยของคุณ ปลดล็อกด้วยความรักเหรอคะ?"

ธันย์จ้องมองดวงตาคู่สวยตรงหน้านิ่ง... ตรรกะอันแสนเนี้ยบเย็นชาของเขาพังทลายลงต่อความรู้สึกที่เอ่อล้นในอก สัญชาตญาณประสาทลึกๆ ที่เคยลืมเลือนไปตื่นขึ้นมาอย่างสมบูรณ์

ธันย์เปลี่ยนสภาพแวดล้อมในสเปซจำลองให้กลายเป็นทิวทัศน์หิมะสีขาวโพลนแสนโรแมนติก หิมะเกล็ดนุ่มโปรยปรายลงมาจากฟ้าเสมือนจริง สะท้อนแสงดาวระยิบระยับ

ร่างสูงสง่าขยับก้าวเข้าประชิด รวบตัวนิ้งเข้ามาในอ้อมกอดแน่นหนา นิ้วเรียวยาวเชิดประคองใบหน้าเนียนหวานของเธอขึ้นสบสายตา นัยน์ตาสีดำสนิทฉายประกายลึกซึ้ง

"ผลการประมวลผลระบุว่า..." ธันย์กระซิบเสียงต่ำทรงเสน่หาลึกซึ้ง "...สถาปนิกคนนี้ ไม่ต้องการคูณสิบสองเท่าในโลกจำลองอีกต่อไปแล้วครับ"

ธันย์โน้มใบหน้าลงประทับจูบแสนอ่อนหวานและลึกซึ้งบนริมฝีปากนุ่มของนิ้ง กลางสเปซหิมะจำลองที่แสนงดงาม...

*วิ้ง...*

[SESSION ISOLATION CORE UNLOCKED]
