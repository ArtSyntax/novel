# THE ECHO — บทที่ 10: กล่องดำในสมอง

**[ECHO ARCHITECTURE LAB – EXECUTIVE SUITE – 03:00 น.]**

หลังจากก้าวออกจากห้อง Isolation Core แผงโฮโลแกรมตรงหน้ากะพริบแสดงเส้นแกนเวลา (Timeline Mapping) 3 จุดที่สว่างวาบขึ้นด้วยแสงสีเงินและสีส้มพลาตินัม

เซนมองแผงประสาทตรงหน้าด้วยสายตาที่คลี่คลายความสงสัยทั้งหมด ร่างสูงสง่าเดินเข้าประชิดตัวรินอย่างช้าๆ

"อธิบายความจริงมาสิ ริน..." เซนเอ่ยเสียงนิ่งทว่านุ่มนวล นัยน์ตาสบประสานเธอลึกซึ้ง "ทำไมรอยตัดแต่งสถาปัตยกรรมประสาทสามชั้น พร้อมลายเซ็น Root Protocol ของผม... ถึงปรากฏอยู่ในสมองของคุณ?"

รินยิ้มเฉลยช้าๆ นัยน์ตาแพรวพราวด้วยความสุขและความทรงจำที่เอ่อล้น

"ทุกครั้งที่ฉันรันโปรโตคอลตัดแต่งลบความทรงจำในหัวคุณเมื่อสามปีก่อน..." รินอธิบายด้วยน้ำเสียงเรียบนิ่งแต่ซ่อนความปวดร้าวในอดีต "...ฉันจะฝัง **Encrypted Mirror Fragment** สำเนาสถาปัตยกรรมประสาทที่ถูกแก้ไขแต่ละชั้นไว้ในหัวของตัวเองด้วย... โดยใช้ Root Protocol ลายเซ็นของคุณเป็นกุญแจล็อก"

เธอเว้นจังหวะ สบตาเธอลึกซึ้ง แววตาสั่นระริก

"เพราะถ้าวันหนึ่งคุณจำเป็นต้องพิสูจน์ความบริสุทธิ์ สมองของฉันจะเป็น *กล่องดำ (Black Box)* ที่เก็บหลักฐานข้อมูลไว้ครบถ้วนทุกชั้น... ตลอดสามปีที่ผ่านมา"

เซนมองดวงหน้าเนียนกลมโตตรงหน้านิ่งอึ้ง... ความจริงทุกอย่างถูกร้อยเรียงประสานกันอย่างสมบูรณ์แบบ ไร้รอยต่อ ไร้ช่องโหว่ทางพล็อต!

"แล้วชั้นที่ 3 ล่ะครับ?" เซนถามต่อ เสียงแผ่วต่ำลงด้วยความห่วงใย

"ชั้นที่ 3 คือ **The Trojan Lock** ที่ฉันล็อกสเปซความทรงจำระยะสั้นของตัวเองและฝังเรื่องแฟนเก่าปลอมๆ ก่อนก้าวเข้าประตูแล็บในวันแรกค่ะ" รินตอบพร้อมรอยยิ้มหวานยั่วเย้า "Trojan Lock ล็อกแค่ข้อมูล surface-level — ชื่อ ภาพหน้า ลำดับเหตุการณ์ในวันนั้น แต่ meta-plan ทั้งหมดยังอยู่ใน long-term memory ของฉัน ฉันยังรู้ว่า 'ฉันมาที่นี่เพื่อทำ back-test' แต่จำรายละเอียดเชิงอารมณ์ไม่ได้แบบ organic จริงๆ... นั่นแหละที่ทำให้ทุกอย่างดูเป็นธรรมชาติ เพื่อดึงคิณเข้ามากระดาน และที่สำคัญที่สุด... มันคือโปรเจกต์ทดสอบสมมติฐานย้อนหลัง (Back-test)"

รินขยับตัวก้าวขึ้นชิดอกหนาของเขา ช้อนสายตามองสบตาในระยะประชิด

"ฉันอยากทดสอบว่า... ต่อให้สมองของคุณจะโดนฉันและรหัสเขียนทับลบความทรงจำเกี่ยวกับฉันออกไปจนเกลี้ยงหัว... ต่อให้ตรรกะอันแสนเนี้ยบเย็นชาของคุณจะมองว่าฉันเป็นแค่ 'ลูกค้าสาวสติแตกน่ารำคาญ'... แต่หากฉันเดินกลับเข้ามาป่วนในชีวิตคุณอีกครั้ง สัญชาตญาณประสาทและหัวใจของคุณ จะยังทำงานและตกหลุมรักผู้หญิงที่ชื่อรินนาราคนเดิมซ้ำอีกรอบไหม"

เซนขยับรอยยิ้มคมคายแสนเสน่หาที่มุมปาก โอบกระชับอ้อมกอดรั้งร่างบางของเธอเข้าชิดอุ่นอกหนาอย่างแสนรัก

"ผลการรันชุดคำสั่งทดสอบ (Back-test)... ได้คะแนนเต็มร้อยครับ คุณผู้บงการ" เซนกระซิบตอบข้างหูเธออย่างแสนหวาน
