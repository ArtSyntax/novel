# THE ECHO — บทที่ 7: การเสียสละเมื่อ 3 ปีก่อน

**[MEMORY ARCHIVE: 3 ปีก่อน – ECHO ARCHITECTURE LAB]**

กับดักของ Aetheris ถูกจุดชนวนขึ้นอย่างเยือกเย็นและโหดเหี้ยม

คิณ (ผู้ถูกฝังความทรงจำปลอม) และ ดร.เดชา นำทีมกฎหมายพร้อมตำรวจบุกเข้ายึด ECHO LAB! พวกเขานำเหตุการณ์ทดลองมนุษย์ที่คิณเคยทำ มาสลับตัวสลับชื่อ ใส่ร้ายเซนว่าแอบทำ *Unconsented Human Experimentation* (แอบทดลองในมนุษย์โดยไม่ได้รับยินยอม)

"ยินดีด้วยนะ เซน!" คิณหัวเราะอย่างสะใจ นัยน์ตาฉายแววผู้ชนะที่คุ้มคลั่ง "สัญญา VC พันล้านระบุชัดเจนว่า ถ้าแกตกเป็นคดีละเมิดจริยธรรม สิทธิบัตรและซอร์สโค้ดในหัวแกทั้งหมดจะตกเป็นของ Aetheris ทันที!"

สถานการณ์ในตอนนั้นมืดมนถึงที่สุด... หากเซนถูกดำเนินคดี เขาจะโดนถอนใบอนุญาต ติดคุก และสิทธิบัตรงานวิจัยระดับโลกจะตกไปอยู่ในมือขององค์กรชั่วร้าย

ในคืนก่อนที่ทีมกฎหมายจะเข้าอายัดข้อมูลชีวประสาท รินเดินเข้ามาหาเซนในห้อง Isolation Core

บรรยากาศในห้องเงียบกริบ แสงไฟสีเงินกะพริบแสงสม่ำเสมอ

"มีทางเดียวที่จะชนะเกมนี้ค่ะ เซน..." รินเอ่ยเสียงสั่นระริก แต่นัยน์ตาเด็ดเดี่ยว "เราต้องใช้ข้อกฎหมาย Plausible Deniability"

เซนมองหน้ารินอย่างเข้าใจทันที... Plausible Deniability คือหลักการทางกฎหมายและประสาทวิทยา หากผู้ถูกกล่าวหา **ไม่มีความทรงจำและซอร์สโค้ดหลงเหลืออยู่ในสมองเลย** การสั่งยึดข้อมูลจากสมองจะกระทำไม่ได้ตามกฎหมาย และคดีความจะตกเป็นโมฆะทันทีเพราะไม่มีหลักฐานความผิดใดๆ ให้พิสูจน์ได้

"คุณต้องลบความทรงจำและซอร์สโค้ดทั้งหมด... ออกจากหัวของตัวเอง" รินเอ่ยพร้อมน้ำตาที่คลอเบ้า มือเรียวยื่นไปจับมือหนาของเขาไว้แน่น "และฉันจะเป็นคนกด Execute จากภายนอกห้อง Isolation Core ให้คุณเอง"

เซนมองหญิงสาวตรงหน้านิ่งสนิท นัยน์ตาสีดำสนิทเต็มไปด้วยความรักและความเชื่อใจ เขาขยับนิ้วเขียนโปรโตคอลสลัก **Digital Signature อนุมัติล่วงหน้า (Pre-authorized digital signature)** ไว้ในระบบประสาทของตนเอง แล้วมอบคีย์ควบคุมให้ริน

แต่ก่อนหน้านั้น เขายังฝังโปรโตคอล Mirror Fragment ไว้ในเซิร์ฟเวอร์ดส็คริปต์ล่วงหน้าด้วยชื่อเดียวกับ Pre-authorized — โปรแกรมที่จะสร้างสำเนาเข้ารหัสของสถาปัตยกรรมประสาทแต่ละชั้นที่ถูกตัดออก แล้วฝังมันไว้ในสมองของรินโดยอัตโนมัติทุกครั้งที่เธอกด Execute รินไม่จำเป็นต้องเป็นสถาปนิกสมอง เธอแค่ต้องกดปุ่มเดียว...

"ฝากดูแลตัวผมในอนาคตด้วยนะ ริน..." เซนกระซิบเบาๆ ก่อนจะเข้ากอดเธอไว้เป็นครั้งสุดท้าย ร่างสูงโอบรัดเธอแน่นหนา ราวกับจะประทับความอบอุ่นนี้ไว้ในวิญญาณ

*วิ้ง...*

รินกดปุ่ม Execute จากภายนอก... รหัสความทรงจำและซอร์สโค้ดในสมองของเซนถูกล้างและตัดแต่งออกจนสะอาดกริบ!

เมื่อเซนตื่นขึ้นมา เขาจำเรื่องงานวิจัยและคดีความไม่ได้เลย ทำให้ทีมกฎหมายของ Aetheris ไม่สามารถอายัดซอร์สโค้ดใดๆ ไปได้ และแล็บได้รับความคุ้มครองทางกฎหมายรอดพ้นจากการ Takeover!

ทว่า... สองสัปดาห์หลังจากนั้น สมองของเซนกลับเกิดภาวะ **Cognitive Rejection & Phantom Memory** ประสาทหลอนคิดถึงใบหน้าและอารมณ์รักที่มีต่อรินขึ้นมาอย่างรุนแรงจนระบบวิเคราะห์ติดขัด รินไม่มีทางเลือก นอกจากต้องรันคำสั่งลบครั้งที่ 2 (Cognitive Stabilization) ลบภาพจำเกี่ยวกับตัวเธอออกจากหัวเซนออกจนหมดสิ้น เหลือไว้เพียงความทรงจำของแล็บ เพื่อรักษาชีวิตของชายผู้เป็นที่รักไว้

รินยอมแบกรับความทรงจำเลวร้ายและความเจ็บปวดไว้เพียงลำพังมาตลอด 3 ปี... รอคอยวันที่เธอจะเดินกลับเข้ามาในแล็บแห่งนี้เพื่อเริ่มต้นกระดานย้อนเกล็ด!
