# THE ECHO — บทที่ 7: การเสียสละเมื่อ 3 ปีก่อน

**[MEMORY ARCHIVE: 3 ปีก่อน – ECHO ARCHITECTURE LAB]**

กับดักของ Aetheris ถูกจุดชนวนขึ้นอย่างเยือกเย็นและโหดเหี้ยม

ภีม (ผู้ถูกฝังความทรงจำปลอม) และ ดร.กานต์ นำทีมกฎหมายพร้อมตำรวจบุกเข้ายึด ECHO LAB! พวกเขานำเหตุการณ์ทดลองมนุษย์ที่ภีมเคยทำ มาสลับตัวสลับชื่อ ใส่ร้ายธันย์ว่าแอบทำ *Unconsented Human Experimentation* (แอบทดลองในมนุษย์โดยไม่ได้รับยินยอม)

"ยินดีด้วยนะ ธันย์!" ภีมหัวเราะอย่างสะใจ นัยน์ตาฉายแววผู้ชนะที่คุ้มคลั่ง "สัญญา VC พันล้านระบุชัดเจนว่า ถ้าแกตกเป็นคดีละเมิดจริยธรรม สิทธิบัตรและซอร์สโค้ดในหัวแกทั้งหมดจะตกเป็นของ Aetheris ทันที!"

สถานการณ์ในตอนนั้นมืดมนถึงที่สุด... หากธันย์ถูกดำเนินคดี เขาจะโดนถอนใบอนุญาต ติดคุก และสิทธิบัตรงานวิจัยระดับโลกจะตกไปอยู่ในมือขององค์กรชั่วร้าย

ในคืนก่อนที่ทีมกฎหมายจะเข้าอายัดข้อมูลชีวประสาท นิ้งเดินเข้ามาหาธันย์ในห้อง Isolation Core

บรรยากาศในห้องเงียบกริบ แสงไฟสีเงินกะพริบแสงสม่ำเสมอ

"มีทางเดียวที่จะชนะเกมนี้ค่ะ ธันย์..." นิ้งเอ่ยเสียงสั่นระริก แต่นัยน์ตาเด็ดเดี่ยว "เราต้องใช้ข้อกฎหมาย Plausible Deniability"

ธันย์มองหน้านิ้งอย่างเข้าใจทันที... Plausible Deniability คือหลักการทางกฎหมายและประสาทวิทยา หากผู้ถูกกล่าวหา **ไม่มีความทรงจำและซอร์สโค้ดหลงเหลืออยู่ในสมองเลย** การสั่งยึดข้อมูลจากสมองจะกระทำไม่ได้ตามกฎหมาย และคดีความจะตกเป็นโมฆะทันทีเพราะไม่มีหลักฐานความผิดใดๆ ให้พิสูจน์ได้

"คุณต้องลบความทรงจำและซอร์สโค้ดทั้งหมด... ออกจากหัวของตัวเอง" นิ้งเอ่ยพร้อมน้ำตาที่คลอเบ้า มือเรียวยื่นไปจับมือหนาของเขาไว้แน่น "และฉันจะเป็นคนกด Execute จากภายนอกห้อง Isolation Core ให้คุณเอง"

ธันย์มองหญิงสาวตรงหน้านิ่งสนิท นัยน์ตาสีดำสนิทเต็มไปด้วยความรักและความเชื่อใจ เขาขยับนิ้วเขียนโปรโตคอลสลัก **Digital Signature อนุมัติล่วงหน้า (Pre-authorized digital signature)** ไว้ในระบบประสาทของตนเอง แล้วมอบคีย์ควบคุมให้นิ้ง

แต่ก่อนหน้านั้น เขายังฝังโปรโตคอล Mirror Fragment ไว้ในเซิร์ฟเวอร์ดส็คริปต์ล่วงหน้าด้วยชื่อเดียวกับ Pre-authorized — โปรแกรมที่จะสร้างสำเนาเข้ารหัสของสถาปัตยกรรมประสาทแต่ละชั้นที่ถูกตัดออก แล้วฝังมันไว้ในสมองของนิ้งโดยอัตโนมัติทุกครั้งที่เธอกด Execute นิ้งไม่จำเป็นต้องเป็นสถาปนิกสมอง เธอแค่ต้องกดปุ่มเดียว...

"ฝากดูแลตัวผมในอนาคตด้วยนะ นิ้ง..." ธันย์กระซิบเบาๆ ก่อนจะเข้ากอดเธอไว้เป็นครั้งสุดท้าย ร่างสูงโอบรัดเธอแน่นหนา ราวกับจะประทับความอบอุ่นนี้ไว้ในวิญญาณ

*วิ้ง...*

นิ้งกดปุ่ม Execute จากภายนอก... รหัสความทรงจำและซอร์สโค้ดในสมองของธันย์ถูกล้างและตัดแต่งออกจนสะอาดกริบ!

เมื่อธันย์ตื่นขึ้นมา เขาจำเรื่องงานวิจัยและคดีความไม่ได้เลย ทำให้ทีมกฎหมายของ Aetheris ไม่สามารถอายัดซอร์สโค้ดใดๆ ไปได้ และแล็บได้รับความคุ้มครองทางกฎหมายรอดพ้นจากการ Takeover!

ทว่า... สองสัปดาห์หลังจากนั้น สมองของธันย์กลับเกิดภาวะ **Cognitive Rejection & Phantom Memory** ประสาทหลอนคิดถึงใบหน้าและอารมณ์รักที่มีต่อนิ้งขึ้นมาอย่างรุนแรงจนระบบวิเคราะห์ติดขัด นิ้งไม่มีทางเลือก นอกจากต้องรันคำสั่งลบครั้งที่ 2 (Cognitive Stabilization) ลบภาพจำเกี่ยวกับตัวเธอออกจากหัวธันย์ออกจนหมดสิ้น เหลือไว้เพียงความทรงจำของแล็บ เพื่อรักษาชีวิตของชายผู้เป็นที่รักไว้

นิ้งยอมแบกรับความทรงจำเลวร้ายและความเจ็บปวดไว้เพียงลำพังมาตลอด 3 ปี... รอคอยวันที่เธอจะเดินกลับเข้ามาในแล็บแห่งนี้เพื่อเริ่มต้นกระดานย้อนเกล็ด!
