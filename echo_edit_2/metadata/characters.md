# THE ECHO (Edit 2) — ตัวละครและประวัติเชิงลึก (Character Profiles)

---

### 1. ธันย์ (ธันยวุฒิ) — The Mind Architect
* **บทบาท:** ผู้อำนวยการและสถาปนิกสมองแห่ง ECHO LAB
* **บุคลิกภาพ:** เย็นชา มินิมอล INTJ ตรรกะเนี้ยบเป๊ะ ไม่เชื่อในอารมณ์ความรู้สึกชั่วคราว
* **ปูมหลัง:** ในอดีตทำวิจัย Memory Architecture Editing ร่วมกับภีม แต่แยกทางกันเพราะยึดมั่นในความปลอดภัย (Non-invasive) กู้เงิน 1,000 ล้านบาทสร้าง Faraday Core ยอมลบความทรงจำตัวเอง 2 ครั้งเมื่อ 3 ปีก่อนตามแผน Plausible Deniability เพื่อรักษาชีวิตและแล็บไว้

---

### 2. นิ้ง (นิชาภา) — The Strategic Strategist
* **บทบาท:** หุ้นส่วนผู้ร่วมก่อตั้ง ECHO LAB / นักจิตวิทยาพฤติกรรม
* **บุคลิกภาพ:** ฉลาด ขี้เล่น มีเสน่ห์ปวนหัว ENTP/ENFP มองการณ์ไกล รักธันย์สุดหัวใจ
* **ปูมหลัง:** รู้จักกับธันย์และภีมตั้งแต่มหาลัย เคยถูกภีมจับไปแอบทดลองตัดแต่งความทรงจำแต่ธันย์บุกช่วยไว้ เป็นคนกด Execute ลบสมองธันย์เมื่อ 3 ปีก่อน และฝัง Encrypted Mirror Fragment (กล่องดำ) ไว้ในหัวตัวเอง

---

### 3. ภีม (ภีมเดช) — The Tragic Rival
* **บทบาท:** ประธาน Aetheris Capital / อดีตเพื่อนสนิทของธันย์
* **บุคลิกภาพ:** ทะเยอทะยาน เอาชนะ เจ้าคิดเจ้าแค้น
* **ปูมหลัง:** เคยเป็นคู่หูวิจัยกับธันย์ แต่ต่อยอดพังสติแตก ถูก ดร.กานต์ แอบตัดแต่งความทรงจำฝังภาพลวงตาว่าตนเองทำสำเร็จแล้ว ทำให้ภีมปักใจเชื่ออย่างบริสุทธิ์ใจว่าธันย์ขโมยงานวิจัยไป

---

### 4. ดร.กานต์ — The Puppet Master
* **บทบาท:** Chief Scientist แห่ง Aetheris Capital
* **บุคลิกภาพ:** เจ้าเล่ห์ โลภ ไร้จริยธรรม ชักใยอยู่เบื้องหลัง
* **ปูมหลัง:** แอบใช้โปรโตคอลประสาทตัดแต่งสมองภีมเพื่อใช้ภีมเป็นหมากหน้าเสื่อในการยึดสิทธิบัตรงานวิจัยพันล้านของธันย์

---

### 5. ปอนด์ — The Systems Engineer
* **บทบาท:** วิศวกรชีวประสาทผู้ช่วยมือขวาของธันย์
* **บุคลิกภาพ:** คล่องแคล่ว ซื่อสัตย์ ช่างสังเกต
* **ปูมหลัง:** คุมระบบเมนเฟรมของแล็บ ป้องกันการแฮก และเป็นคนรันระบบ Data Avalanche ทำลายคลาวด์ Aetheris
