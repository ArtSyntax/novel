# THE ECHO (Edit 2) — คำศัพท์เฉพาะทาง (Glossary)

* **Symmetric Decoupling**: การแยกส่วนเชื่อมต่อข้อมูลความทรงจำเชิงเนื้อหาออกจากอารมณ์ความรู้สึกอย่างสมบูรณ์
* **Memory Architecture Editing**: การตัดแต่งสถาปัตยกรรมความทรงจำระดับนาโนเมตรโดยไม่ทำลายโครงสร้างสมอง
* **Data Avalanche**: ภาวะหิมะถล่มข้อมูล ที่ข้อมูลขยะจะขยายตัวนับล้านเท่าขัดขวางและเข้าแฮกทำลายระบบผู้คัดลอกโดยไม่ได้รับอนุญาต
* **Encrypted Mirror Fragment**: ชิ้นส่วนสถาปัตยกรรมข้อมูลประสาทที่ถูกคัดลอกและเข้ารหัสกระจกเงาคู่ขนานไว้ในอีกจุดหนึ่งเพื่อทำหน้าที่เป็นสำรองข้อมูลความทรงจำ (Black Box)
* **The Trojan Lock**: การล็อกสเปซความทรงจำระยะสั้นและฝังเรื่องราวปลอมเพื่อล่อศัตรูเข้ามากระดานและทำ Back-test
* **Back-test**: กระบวนการนำแบบจำลองการประสานงานมาทดสอบกับสัญชาตญาณย้อนหลัง เพื่อดูว่าหัวใจจะยังตอบสนองเหมือนเดิมไหม
* **Plausible Deniability**: กลยุทธ์ทางกฎหมายและการประสาทวิทยาที่ลบข้อมูลความทรงจำออกจนหมดสิ้น ทำให้ไม่เหลือหลักฐานความผิดใดๆ ตามกฎหมาย
* **Coherent HRV + Oxytocin Sync**: การสอดคล้องของอัตราการเต้นหัวใจและสารฮอร์โมนแห่งความรัก ใช้เป็น Biometric Lock ปลดล็อกระบบ
* **Time Dilation 12x**: โปรโตคอลการบีบอัดเวลาจำลองประสาท ทำให้ 12 ชั่วโมงในสเปซจำลองเท่ากับ 1 ชั่วโมงในโลกจริง
* **Escrow Account Settlement**: ระบบการชำระหรือตกลงเคลียร์ทรัพย์สินผ่านบัญชีตัวกลางเพื่อล้างพันธนาการหนี้สินเดิม
* **Isolation Core**: แกนนิวเคลียสประมวลผลข้อมูลส่วนที่แยกขาดจากเครือข่ายภายนอกแบบ 100%
* **Faraday Cage**: กรงฟาราเดย์ที่บุด้วยโลหะรอบห้องทดลองเพื่อบล็อกคลื่นแม่เหล็กไฟฟ้าและสัญญาณไร้สายภายนอก
* **Pre-authorized digital signature**: ลายเซ็นดิจิทัลที่ได้รับการเข้ารหัสและอนุมัติสิทธิ์การทำงานไว้ล่วงหน้า
* **Local guest Wi-Fi Exploit**: ช่องโหว่การแฮกเจาะระบบผ่านการเชื่อมต่อ Wi-Fi ในพื้นที่สำหรับแขกภายนอก
* **Perpetua Partnership**: โครงการร่วมทุนหรือสัญญาหนี้ VC 1,000 ล้านบาทที่เป็นกับดักของ Aetheris
* **Data Slicing**: การตัดแบ่งชุดข้อมูลประสาทออกเป็นส่วนย่อยๆ อย่างประณีต
* **Non-invasive Neural Pods**: อุปกรณ์รับส่งสัญญาณประสาทจำลองแบบไม่ต้องผ่าตัดฝังในสมอง
* **รหัส Root / Root Protocol**: สิทธิ์และคีย์การควบคุมสูงสุดของระบบปฏิบัติการประสาทที่อนุญาตให้ผู้รันแก้ไขหรือล้างโครงสร้างไฟล์สมองระดับลึกสุดได้
