# THE ECHO — คำศัพท์เฉพาะทาง (Glossary)

เอกสารรวบรวมคำอธิบายและนิยามเชิงเทคนิคและวิทยาศาสตร์ประสาทที่ใช้ในนิยายเรื่อง **THE ECHO** สำหรับใช้แสดงผลคำอธิบายเมื่อผู้อ่านชี้คำศัพท์เหล่านั้นบนหน้าเว็บไซต์

---

*   **Symmetric Decoupling**: การแยกส่วนเชื่อมต่อข้อมูลความทรงจำเชิงเนื้อหาออกจากอารมณ์ความรู้สึกอย่างสมบูรณ์
*   **Data Avalanche**: ภาวะหิมะถล่มข้อมูล ที่ข้อมูลขยะจะขยายตัวขัดขวางและเข้าแฮกทำลายระบบของผู้พยายามคัดลอกไฟล์โดยไม่ได้รับอนุญาต
*   **Coherent HRV**: ความแปรปรวนของอัตราการเต้นของหัวใจแบบประสานสอดคล้อง ซึ่งเป็นค่าสัญญาณชีพที่แสดงถึงความผ่อนคลายและความปลอดภัยระดับลึก
*   **Oxytocin**: สารเคมีประสาทหรือฮอร์โมนแห่งความรักความไว้วางใจ ใช้ร่วมกับ Coherent HRV ในการทำหน้าที่เป็นกุญแจล็อกชีวภาพ
*   **Faraday Cage**: กรงฟาราเดย์ที่บุด้วยโลหะรอบห้องทดลองเพื่อสะท้อนคลื่นแม่เหล็กไฟฟ้าและบล็อกการเชื่อมต่อไร้สายภายนอก 100%
*   **Air-gapped**: การแยกอุปกรณ์หรือระบบคอมพิวเตอร์ออกจากอินเทอร์เน็ตและเครือข่ายสัญญาณภายนอกแบบเด็ดขาดทางกายภาพ
*   **Time Dilation**: โปรโตคอลการบีบอัดและขยายเวลาจำลองประสาท ทำให้เวลาในโลกจำลองเดินเร็วกว่าโลกภายนอกถึง 12 เท่า
*   **Permanent Void**: ภาวะสุญญากาศความทรงจำถาวร เกิดจากการล้างและเขียนทับข้อมูลประสาทที่ตำแหน่งเดิมซ้ำซ้อนเกิน 3 ครั้ง
*   **Zero-day**: ช่องโหว่ความปลอดภัยของระบบคอมพิวเตอร์ที่ยังไม่มีการค้นพบอย่างเป็นทางการหรือยังไม่มีระบบแก้ไขป้องกัน
*   **Root Credentials**: รหัสและสิทธิ์ยืนยันตัวตนระดับลึกสุดของสถาปนิกผู้ดูแลระบบ (Administrator) เพื่อควบคุมแกนกลางระบบปฏิบัติการ
*   **Root Protocol**: โปรโตคอลควบคุมสูงสุดที่ใช้เข้าถึงและสั่งการระบบประสาทส่วนกลางแบบเต็มสิทธิ์ ไม่ผ่านการคัดกรองความปลอดภัยทั่วไป
*   **Remapping**: การเขียนและเชื่อมโยงโครงสร้างแผนที่กระแสประสาท (Neural Mapping) ใหม่ เพื่อเปลี่ยนแปลงหรือสร้างการรับรู้และการเชื่อมโยงข้อมูลใหม่
*   **Local guest Wi-Fi Exploit**: ช่องโหว่การแฮกเจาะระบบผ่านการเชื่อมต่อ Wi-Fi ในพื้นที่สำหรับแขกภายนอก เพื่อข้ามผ่านไฟร์วอลล์เข้าไปยังระบบภายในที่ขาดการแยกวงเครือข่ายที่ดีพอ
*   **Escrow Account Settlement**: ระบบการชำระหรือตกลงเคลียร์ทรัพย์สินผ่านบัญชีตัวกลางที่จะโอนย้ายมูลค่าให้ปลายทางโดยอัตโนมัติก็ต่อเมื่อเงื่อนไขเชิงตัวเลขหรือผลลัพธ์ของระบบสำเร็จครบถ้วน
*   **Isolation Core**: แกนนิวเคลียสประมวลผลข้อมูลส่วนที่แยกขาดจากเครือข่ายและระบบอื่นๆ โดยสิ้นเชิง ป้องกันการรั่วไหลและการแทรกแซงจากภายนอก
*   **Root File**: ไฟล์หลักที่เป็นแกนกลางและเป็นจุดอ้างอิงสูงสุดในการรันโปรโตคอลระบบการทำงานและโครงสร้างข้อมูลประสาท
*   **Pre-authorized signature**: ลายเซ็นดิจิทัลที่ได้รับการเข้ารหัสและอนุมัติสิทธิ์การทำงานไว้ล่วงหน้า เพื่อให้ระบบสามารถ Execute คำสั่งเฉพาะได้ทันทีโดยไม่ต้องรอขั้นตอนการยืนยันตัวตนใหม่ในระหว่างเชื่อมต่อ
*   **Back-test**: กระบวนการนำซอฟต์แวร์หรือแบบจำลองการประสานงานมาทดสอบกับข้อมูลย้อนหลังในอดีต เพื่อตรวจสอบประสิทธิภาพและความเสถียรของเงื่อนไขที่ตั้งขึ้น
*   **Encrypted Mirror Fragment**: ชิ้นส่วนสถาปัตยกรรมข้อมูลประสาทที่ถูกคัดลอกและเข้ารหัสกระจกเงาคู่ขนานไว้ในอีกจุดหนึ่งเพื่อทำหน้าที่เป็นสำรองข้อมูลความทรงจำ (Black Box)
*   **Perpetua Partnership**: โครงการร่วมทุนหรือข้อตกลงความร่วมมือระยะยาวที่เป็นนิรันดร์ระหว่างหน่วยงานหรือผู้พัฒนาระบบเทคโนโลยีประสาท
*   **Data Slicing**: การตัดแบ่งชุดข้อมูลประสาทออกเป็นส่วนย่อยๆ อย่างประณีต เพื่อสกัดหรือแยกเฉพาะส่วนของความทรงจำเป้าหมายโดยไม่กระทบข้อมูลข้างเคียง
*   **Non-invasive Neural Pods**: อุปกรณ์รับส่งสัญญาณประสาทจำลองแบบไม่ต้องผ่าตัดฝังในสมอง ใช้การส่งสัญญาณผ่านคลื่นความถี่เชื่อมต่อจากภายนอกเพื่อสร้างพื้นที่เสมือน
*   **รหัส Root**: สิทธิ์และคีย์การควบคุมสูงสุดของระบบปฏิบัติการประสาทที่อนุญาตให้ผู้รันแก้ไขหรือล้างโครงสร้างไฟล์สมองระดับลึกสุดได้
