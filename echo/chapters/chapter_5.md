# THE ECHO — บทที่ 5: ประมูลลวง

**[THE GRAND CRYSTAL BALLROOM – GRAND HYATT BANGKOK – 19:30 น.]**

งานแถลงข่าวและประมูลนวัตกรรมดิจิทัลของสมาคมฟินเทคประจำปี (Deep Tech & Financial Innovation Summit) ถูกจัดขึ้นอย่างหรูหราอลังการ

แสงจากโคมไฟระย้าคริสตัลดวงโตกองร้อยระยิบระยับสะท้อนกับแก้วแชมเปญชั้นเลิศและวัสดุตกแต่งขัดเงา ผู้เข้าร่วมงานกว่าห้าร้อยชีวิตคือระดับซีอีโอบริษัท Deep Tech นักลงทุนสถาบันการเงิน และผู้บริหาร Venture Capital พันล้านที่เป็นฟันเฟืองขับเคลื่อนเทคโนโลยีของประเทศ

ธันย์ยืนอยู่ตรงมุมเงียบของงานเลี้ยงในชุดทักซิโด้สีกราไฟต์ตัดเย็บเนี้ยบกริบสไตล์ Modern Minimalist ปราศจากโบว์ไทหรือพินประดับอันซับซ้อน แต่เส้นตรงของแนวทักซิโด้กลับขับเน้นให้เขาดูสง่างามและคมกริบดั่งนักวางกลยุทธ์ เขายืนประคองแก้วสปาร์กลิงวอเตอร์ กวาดสายตาคมวิเคราะห์สถิติความเคลื่อนไหวของผู้คนในห้องโถงใหญ่อย่างเงียบๆ

ข้างกายของเขาคือ นิ้ง ในชุดเดรสยาวเกาะอกสีพลาตินัมโโกลด์เรียบหรูที่เผยให้เห็นแผ่นหลังเนียนและลำคอระหง ข้อมือซ้ายของเธอยังคงสวมกำไลกราไฟต์ขัดด้านอันเดิมอย่างเปรียบต่างกับความหรูหราของเดรส เธอจิบแชมเปญพลางส่งรอยยิ้มทรงเสน่ห์และป่วนสายตาให้แก่ผู้บริหารที่เดินผ่านไปมา

“นักลงทุนในห้องนี้ 85% กำลังจับตาดูว่า ECHO LAB จะถูก Aetheris บีบกลืนกินสิทธิบัตรคืนนี้ไหม” นิ้งกระซิบข้างหูธันย์ เสียงหวานเจือกระแสล้อเลียนความตึงเครียด “คุณภีมจัดฉากและปั่นกระแสข่าวงานนี้ขึ้นมาเพื่อกดดันคุณต่อหน้าสาธารณชนโดยเฉพาะเลยนะคะ”

“การปล่อยให้ศัตรูประเมินตัวเองไว้สูง และมั่นใจว่าถือไพ่คุมกระดาน... คือจุดเริ่มต้นของความพ่ายแพ้ที่คำนวณมาอย่างดีที่สุด” ธันย์ตอบกลับเสียงนิ่งสนิท นัยน์ตามองตรงไปยังเวทีใหญ่

*แปะ... แปะ... แปะ...*

เสียงปรบมือดังขึ้นเป็นจังหวะต้อนรับผู้ดำเนินงาน ภีมก้าวขึ้นไปยืนหลังโพเดียมกระจกนิรภัยกลางเวทีใหญ่ด้วยรอยยิ้มสง่างามทรงภูมิฐาน นัยน์ตาใต้แว่นกรอบบางสแกนมองมายังจุดที่ธันย์และนิ้งยืนอยู่ด้วยแววตาของผู้กุมชัยชนะสูงสุด

“สวัสดีแขกผู้มีเกียรติทุกท่านครับ” ภีมเอ่ยผ่านระบบไมโครโฟนไร้สาย โทนเสียงนุ่มทว่าเต็มไปด้วยการแสดงอำนาจ “ในค่ำคืนนี้ Aetheris Capital มีความยินดีที่จะประกาศการประมูลเสนอสิทธิ์เข้าถึง ‘อัลกอริทึมต้นแบบการคุมโครงสร้างอารมณ์ประสาท’ ซึ่งพัฒนาโดยทีมวิจัยที่ Aetheris กำลังจะเข้าครอบครองกิจการในเร็ววันนี้”

เสียงฮือฮาดังเซ็งแซ่ขึ้นมาทันทีทั่วทั้งห้องบอลรูม! ภีมกำลังใช้แรงกดดันทางสังคมบีบให้แล็บของธันย์กลายเป็นของเล่นในตลาดการเงิน ก่อนวันครบกำหนดสัญญาหุ้นกู้แปลงสภาพเพียงวันเดียว

บนหน้าจอยักษ์ด้านหลังเวที ปรากฏโค้ดสัญลักษณ์กระแสประสาทสีเงินที่จำลองการรันระบบ Symmetric Decoupling—มันคือไฟล์ข้อมูลจำลองที่ ดร.กานต์ แอบเจาะดูดไปจากเครื่องตรวจวิเคราะห์ของนิ้งเมื่อบ่ายวานนี้ ดร.กานต์ ที่นั่งเด่นอยู่ข้างเวทียิ้มเยาะอย่างสะใจ เพราะคิดว่าตนเองได้ครอบครองผลงานชิ้นโบแดงมาฉีกหน้าลูกศิษย์อย่างธันย์ได้แล้ว

“ราคาเสนอซื้อขั้นต้นสำหรับสิทธิ์การใช้ซอฟต์แวร์นี้... อยู่ที่สามร้อยล้านบาทครับ” ภีมประกาศยิ้มแย้ม

“ห้าร้อยล้านบาท!” ผู้แทนทุนใหญ่ฝั่งซ้ายขานราคารวดเร็ว

“เจ็ดร้อยล้านบาท!” VC พันล้านฝั่งตรงข้ามยกมือขานแข่งอย่างไม่ยอมกัน

นิ้งเหลือบสายตามองธันย์ “ภีมกำลังใช้ลิขสิทธิ์ปลอมนี่ปั่นกระแสความน่าเชื่อถือให้มูลค่าหุ้น Aetheris Cloud พุ่งขึ้นสูงสุดขีด... ถ้าปล่อยให้เคาะจบการประมูล ภีมจะได้เงินสดและเครดิตสิทธิบัตรไปฟรีๆ คุณจะปล่อยให้เกมนี้ดำเนินต่อไปเหรอคะ คุณสถาปนิก?”

ธันย์จิบน้ำแร่อย่างช้าๆ นัยน์ตาคมสะท้อนแสงไฟประมูล เขานับถอยหลังจังหวะในระบบประมวลผลอย่างแม่นยำ... 3... 2... 1...

“แปดร้อยล้านบาท!” ภีมขานเสียงดังขึ้น “มีท่านใดจะเสนอราคาเหนือกว่านี้เพื่ออัลกอริทึมที่จะปฏิวัติ—”

“เก้าอี้ที่คุณกำลังเร่ขายน่ะ... มันไม่มีขาสำหรับรองรับน้ำหนักระบบหรอกครับ คุณภีม”

เสียงนิ่งเข้มและทรงพลังของธันย์ดังขัดจังหวะขึ้นท่ามกลางความเงียบกลางฮอลล์ใหญ่! รังสีความมั่นใจสยบทุกความเคลื่อนไหวจนนักข่าวและนักลงทุนหันขวับมามองสถาปนิกหนุ่มเป็นจุดเดียว

ธันย์ก้าวเดินออกไปด้านหน้าอย่างสง่างาม มือขวาชูรีโมตสัญญาณควบคุมขนาดจิ๋วสีกราไฟต์ขึ้นมา

“ไฟล์ข้อมูลจำลองที่คุณภีมกำลังเสนอขายอยู่นั้น... คือข้อมูลขยะ (Honeypot Data) ที่ระบบตรวจวิเคราะห์ของผมจงใจปล่อยให้ ดร.กานต์ แฮกไปเมื่อวันก่อน” ธันย์ยกมุมปากยิ้มหยัน แววตาสบประสาน ดร.กานต์ ที่บัดนี้เริ่มหน้าถอดสี “และหากใครก็ตามนำรหัสชุดนี้ไปรันระบบภายในสามนาที ข้อมูลขยะจะขยายตัวนับล้านเท่าและเกิดภาวะ Data Avalanche ทำลายสแต็กเซิร์ฟเวอร์คลาวด์ของคุณจนพังทลายอย่างสมบูรณ์”

“โกหก! แกใส่ร้าย!” ดร.กานต์ ลุกขึ้นยืนชี้หน้าสติแตก “ฉันถอดรหัสตรวจสอบโครงสร้างอัลกอริทึมด้วยตัวเองแล้ว! มันคือรหัส Symmetric Decoupling ของจริง!”

“รหัสและลิขสิทธิ์ของจริงน่ะ... อยู่ตรงนี้ต่างหากค่ะ” นิ้งก้าวเดินขึ้นมายืนเคียงข้างธันย์ เธอแตะสัมผัสบนชิปกราไฟต์ที่กำไลข้อมือ แสงโฮโลแกรมสว่างวาบขึ้นสลักเป็นสเปกตรัมโค้ดสีเงินวาวสมบูรณ์แบบสามมิติกลางอากาศ “และสิทธิบัตรฉบับนี้ ได้รับการอนุมัติการสลักสิทธิ์ลำดับความสำคัญ จดทะเบียนร่วมกันระหว่างสถาบันวิจัยประสาทวิทยาศาสตร์นานาชาติ และ ECHO LAB เรียบร้อยแล้วตั้งแต่เมื่อสามชั่วโมงที่ผ่านมา”

เสียงฮือฮาดังลั่นระเบิดขึ้นกว่าเดิม! แฟลชกล้องถ่ายภาพของกลุ่มสื่อมวลชนรัวสว่างวาบเข้าใส่ใบหน้าซีดตึงของภีมและ ดร.กานต์ บนเวทีอย่างรุนแรง

ภีมยืนกำมือแน่นหลังโพเดียม สีหน้าหล่อเหลาบัดนี้เรียบตึงและเย็นเฉียบ รอยยิ้มแบบนักธุรกิจหายไปสิ้น หุ้น Aetheris Cloud ที่เขากำลังปั่นราคาจะดิ่งร่วงทะลุเหวทันทีที่ข่าวสิทธิบัตรปลอมและวิกฤตความปลอดภัยแพร่ออกไปในอีกไม่กี่นาทีข้างหน้า เพื่อพยุงราคาหุ้นของบริษัทไม่ให้ล้มละลาย ภีมไม่มีทางเลือกอื่นนอกจากบีบซื้อสิทธิ์จริงนี้คืนเพื่อปิดข่าวเงียบ!

ภีมสูดลมหายใจกดดันความเดือดดาลลงลึก ก่อนจะกดไมโครโฟนขานราคาเสียงลอดไรฟัน

“หนึ่งพันล้านบาท...” ภีมประกาศกร้าว “Aetheris ขอเสนอซื้อสิทธิบัตรฉบับจริงในมูลค่าหนึ่งพันล้านบาทถ้วน... ชำระผ่านระบบ Escrow Account Settlement ทันทีคืนนี้”

ความเงียบกริบโรยตัวครอบงำห้องจัดเลี้ยง ภีมเพิ่งจะจ่ายเงินพันล้านบาทเพื่อซื้อความอยู่รอดของตัวเองด้วยหมากที่ธันย์วางไว้

ธันย์สบตาภีมอย่างไร้ความปรานี ก่อนเอ่ยเสียงเรียบ

“ขอบคุณสำหรับเงินพันล้านครับ คุณภีม... เงินสดก้อนนี้จะถูกโอนตรงเข้าบัญชีสถาบันวิจัยฯ และ ศ.ธีระ จะอนุมัติจ่ายเป็นงบวิจัยฉุกเฉินโอนตรงมายัง ECHO LAB เพื่อหักล้างยอดหนี้หุ้นกู้แปลงสภาพที่คุณถือครองอยู่โดยอัตโนมัติภายในคืนนี้ สัญญาหนี้ระหว่างเรา... ถือเป็นโมฆะ”

**[THE BALCONY – 22:00 น.]**

ลมยามดึกพัดเอื่อยผ่านระเบียงกระจกของโรงแรมหรู แสงไฟหลากสีของตึกรามบ้านช่องในกรุงเทพมหานครส่องสว่างสะท้อนระยิบระยับ

นิ้งยืนประคองแก้วแชมเปญพิงขอบระเบียง ยิ้มอย่างสะใจในชัยชนะอันงดงาม “ใช้เงินสดพันล้านของศัตรู มาจ่ายคืนหนี้ที่ศัตรูถือครองอยู่... เป็นกลยุทธ์ Back-test ทางการเงินที่เนี้ยบกริบมากค่ะ คุณผู้อำนวยการ”

ธันย์ก้าวเดินมาหยุดยืนเคียงข้างเธอ สายลมโชยพัดเส้นผมสีดำของเขาเบาๆ “ถ้าไม่ได้ข้อมูลสิทธิบัตรที่ถูกล็อกและจดค้างไว้ร่วมสถาบันฯ แผนนี้ก็ไม่มีทางเสร็จสิ้น... คุณเตรียมการเรื่องนี้ล่วงหน้าไว้ตั้งแต่เมื่อไหร่กันแน่ นิ้ง?”

นิ้งนิ่งอึ้งไปชั่วครู่ รอยยิ้มขี้เล่นปนป่วนบนใบหน้าค่อยๆ จางหายไป เหลือเพียงนัยน์ตาสีน้ำตาลเข้มลึกซึ้งที่มองทอดออกไปในแสงไฟระยิบระยับของเมืองใหญ่

“นาน... นานพอๆ กับเวลาที่ฉันรอให้คุณจำเรื่องของเราได้นั่นแหละค่ะ” นิ้งพึมพำเสียงแผ่วเบาแทบหายไปกับสายลม

ธันย์จ้องมองดวงหน้าเนียนของเธอ สมองอันปราดเปรื่องประมวลผลคำพูดและปมลายเซ็นรหัสลบความจำซ้อน 3 ครั้งในหัวเธอทันที... ปริศนาความสัมพันธ์ในอดีตกำลังบีบตัวแน่นเข้าหากัน

ธันย์ยื่นมือขวาไปกุมมือเรียวของนิ้งที่กำลังถือแก้วแชมเปญไว้ นิ้วเรียวกระชับแน่นสัมผัสได้ถึงความเย็นของแก้วและความอบอุ่นของฝ่ามือเธอ

*ติ๊ด... ติ๊ด...*

ทันใดนั้น คอนแทกต์เลนส์สแกนเนอร์ของธันย์สว่างวาบกะพริบแจ้งเตือนระดับสีแดงฉุกเฉินจากเซิร์ฟเวอร์แล็บ

[SYSTEM ALERT: REMOTE SCANNING DETECTED FROM AETHERIS NODE]
[TARGET PROTOCOL ENGAGED: SAFE MODE ACTIVE ON TARGET (NICHAPHA)]
[COUNTER PAYLOAD DELIVERED: DATA AVALANCHE TRIGGERED ON SENDER]

ธันย์มองหน้าจอแจ้งเตือนด้วยสายตากร้าวและคมกริบขั้นสุด ก่อนจะจุดรอยยิ้มเหยียดที่มุมปากเมื่ออ่านผลลัพธ์

“ดร.กานต์ พยายามส่งคำสั่งลอบสแกนระบบประสาทของคุณระยะไกลหลังจากงานเลิก...” ธันย์เอ่ยเสียงต่ำ “แต่รหัสทำลายตัวเอง (Self-Destruct) ที่ผมฝังไว้ทำงานเรียบร้อย... สมองของคุณถูกล็อกเข้า Safe Mode ปลอดภัย และระบบคลาวด์ Aetheris Cloud กำลังถล่มทลายลงด้วยสภาวะ Data Avalanche ณ วินาทีนี้”

นิ้งหันมองสบตากับเขา แววตาสั่นระริกด้วยความรู้สึกอันหลากหลายที่เปี่ยมล้น

“พรุ่งนี้... เราจะเข้าสู่ Isolation Core” ธันย์เอ่ยเสียงต่ำ ทรงพลังและเฉียบขาด “ผมจะสแกน Root File ชั้นในสุดของระบบสมองคุณ... และผมต้องหาคำตอบให้ได้ว่า คุณซ่อนความทรงจำอะไรเกี่ยวกับอดีตของเราไว้กันแน่ นิ้ง”

นิ้งสบตากับธันย์ เธอไม่ดึงมืออกแต่มองเขาด้วยรอยยิ้มเปราะบางที่ซ่อนความเศร้าไว้ลึกๆ
