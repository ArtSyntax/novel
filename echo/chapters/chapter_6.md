# THE ECHO — บทที่ 6: หิมะจำลอง

**[ECHO ARCHITECTURE LAB – ISOLATION CORE – 01:30 น.]**

เพื่อป้องกันความผิดพลาดทางข้อมูลจากการเหนี่ยวนำสัญญาณภายนอกและแผงจารกรรมใดๆ หลังการถล่มของ Aetheris Cloud ธันย์สั่งการย้ายระบบวิเคราะห์กระแสประสาทลงมายังห้องควบคุมนิรภัยฉุกเฉินชั้นใต้ดิน ‘Isolation Core’

ห้องรูปทรงสี่เหลี่ยมด้านเท่าทำจากผนังฉนวนตะกั่วหนาหน่วงและห่อหุ้มด้วยกรงฟาราเดย์ (Faraday Cage) ปิดกั้นคลื่นไฟฟ้า สัญญาณโทรศัพท์ หรือรังสีทางวิทยาศาสตร์ทุกประเภทจากภายนอกโดยสมบูรณ์ ความเงียบภายในห้องนี้ลึกซึ้งดั่งลอยคว้างอยู่กลางห้วงอวกาศอันมืดมิด

นิ้งนอนสงบอยู่บนเตียงปรับระดับขัดด้าน วงแหวนแสงของอุปกรณ์เหนี่ยวนำประสาทสีกราไฟต์หมุนวนเงียบเชียบเรืองแสงจางๆ รอบขมับของเธอ ธันย์ยืนจัดแผงควบคุมอยู่ข้างเตียง สวมหูฟังเชื่อมสัญญาณประสาทส่วนตัวและคีย์ป้อนชุดคำสั่งตรวจวิเคราะห์ระดับลึก

“ระบบกำลังจะดึงสติเข้าสู่ชั้นระบบประสาทส่วนลิมบิก” ธันย์เอ่ยเสียงนิ่งเตือนผ่านระบบอินเตอร์คอมภายใน “ฉากจำลองประสาทรอบนี้จะตอบสนองต่อค่าเคมีอารมณ์และจิตใต้สำนึกของคุณโดยสมบูรณ์ หากคุณฝืนเก็บซ่อนไฟล์หรือแอบสั่งล็อกระดับลึก... แรงต้านกลับของระบบจำลองอาจทำให้เกิดความเค้นประสาททางกายภาพจริงได้”

“ฉันไม่เคยแอบซ่อนหรือพยายามต่อต้านสัญญาณของคุณเลยค่ะ ธันย์...” เสียงนิ้งแผ่วเบากระซิบตอบกลับผ่านหูฟังของเขา “...มีแต่คุณนั่นแหละที่พยายามใช้ตรรกะกั้นสัญญาณความรู้สึกของตัวเองตลอดเวลา”

*วิ้งงงงง—*

แผงสัญญาณรันครบ 100% ในเสี้ยววินาที สติสัมปชัญญะของทั้งสองถูกดึงเข้าสู่ระบบจำลองสเปซประสาท

**[SIMULATION SPACE – THE SNOW ISOLATION]**

**[TIME DILATION FACTOR: 12.0x ACTIVE – 6 HOURS SIMULATED / 30 MINUTES REAL-WORLD]**

สัมผัสแรกที่กระแทกเข้าใส่ตัวตนจำลองประสาทของธันย์คือ ความเย็นเยือกยะเยียบระดับติดลบ ลมหนาวพัดเอาเกล็ดหิมะสีขาวละมุนโปร่งร่วงพรูลงมาจากท้องฟ้าสลัวสีเทามุกรอบทิศทาง

ทิวทัศน์รอบตัวไม่ใช่ร้านกาแฟหรือเพนท์เฮาส์หรูหราอีกต่อไป แต่คือเทือกเขาหิมะอันกว้างใหญ่ไพศาลที่สงัดและไร้เสียงสรรพสิ่งรบกวน ตรงบริเวณขอบสันเขาสูง มีเพียงบ้านเรือนกระจกสไตล์ Modern Minimalist หลังเล็กตั้งอยู่อย่างโดดเดี่ยว ท่ามกลางแสงไฟสีส้มอบอุ่นเรืองแสงเรืองออกมาจากภายในกระจกใส

ธันย์อยู่ในชุดโค้ทกันหนาวสีเทาชาร์โคลหนา เขาเดินลุยหิมะนุ่มหนาเต่อก้าวเข้าไปยังบ้านกระจกอย่างระมัดระวัง ประตูกระจกบานใหญ่เลื่อนปิดล็อกทันทีตามโปรแกรมคุมระบบความปลอดภัยส่วนตัว มองเห็นนิ้งในชุดเสื้อไหมพรมถักสีครีมนุ่มนวลนั่งประคองถ้วยโกโก้ร้อนส่งไอสีขาวฟุ้งอยู่ริมบานหน้าต่างใหญ่

“สเปซเทือกเขาหิมะ...” ธันย์เอ่ยเสียงต่ำก้าวเดินก้าวเข้ามาในสเปซบ้าน “นี่ไม่ใช่ไฟล์ความจำเก่าที่คุณดึงมา... แต่มันคือสเปซที่คุณเพิ่งสร้างขึ้นใหม่สดๆ ในหัว”

“ยินดีต้อนรับสู่พื้นที่จำลองส่วนตัวของฉันค่ะ คุณสถาปนิก” นิ้งหันมาสบตาแย้มยิ้มหวาน ทว่านัยน์ตาคู่สวยกลับเต็มไปด้วยความท้าทายลึกซึ้ง “สเปซนี้ถูกล็อกจากภายในด้วยโปรโตคอลเฉพาะตัว... มันจะปิดตายไร้ทางออกจนกว่าคุณจะไขรหัสชั้น Root สำเร็จ”

ธันย์พยายามยกมือขวาเรียกหน้าจอโฮโลแกรมควบคุมส่วนตัวขึ้นมาตรวจสอบรหัส แต่กลับพบว่าหน้าจออินเตอร์เฟซเป็นสีเทาว่างเปล่า ไร้ปุ่มสั่งการทำงาน

[WARNING: SAFETY VALVE LOCKED BY TARGET]
[MANUAL OVERRIDE REQUIRED: BIOMETRIC RECOGNITION]

ธันย์ขมวดคิ้วลึก หันสายตาคมมองนิ้งนิ่ง “คุณจงใจบล็อกและปิดทางระบบความปลอดภัย Safety Valve จากข้างใน? นิ้ง... การทำแบบนี้ถ้าระบบประสาทรวน ทั้งคุณและผมจะติดค้างในสเปซความเย็นติดลบนี้จนกว่าเซิร์ฟเวอร์หลักภายนอกจะรันโปรเซสรีเซ็ตระบบในอีกสิบสองชั่วโมงข้างหน้าจำลอง”

“ฉันทราบดีค่ะ” นิ้งประคองถ้วยโกโก้วางลงบนโต๊ะไม้กลม ค่อยๆ ลุกขึ้นก้าวเดินเข้าหาธันย์ช้าๆ เสียงเท้าสัมผัสพื้นไม้ดังชัดเจนท่ามกลางความเงียบงัน “สิบสองชั่วโมงข้างในนี้ เท่ากับเวลาโลกภายนอกเพียงหนึ่งชั่วโมง... และในสเปซแห่งหิมะและความเงียบนี้ ไม่มีภีม ไม่มีคดีสิทธิบัตร ไม่มีหนี้หุ้นกู้พันล้านรบกวน”

นิ้งเดินเข้ามาหยุดยืนอยู่ตรงหน้าธันย์ ระยะห่างลดลงจนสัมผัสได้ถึงกลิ่นอายอุ่นของเธอ ท่ามกลางความหนาวติดลบ

“มีเพียงฉัน... กับคุณสถาปนิกหน้านิ่งที่ใช้คำว่าตรรกะเป็นเกราะเหล็กบังความรู้สึกตัวเองมาตลอด”

“คุณต้องการอะไรจากผมกันแน่ นิ้ง?” ธันย์ถามเสียงต่ำต่ำ นัยน์ตาสบจ้องลึก หัวใจของเขาเริ่มเต้นรัวสะท้อนความรู้สึก

“ฉันต้องการความจริงใจค่ะ” นิ้งยกมือเรียวขึ้นมาทาบสัมผัสบนปกเสื้อโค้ทหนาของเขา นิ้วเรียวลากไล้เบาๆ ขึ้นมาแตะที่สันกรามคมสันของชายหนุ่ม “ตลอดเวลาที่ผ่านมา... คุณใช้สูตรคำนวณ ใช้ทฤษฎีวิชาการ จัดระเบียบความทรงจำฉันเหมือนวิศวกรจัดไฟล์งาน... แต่สิ่งเดียวที่คุณไม่เคยยอมคำนวณลงตารางสถิติ คือความรู้สึกเวลาคุณอยู่ใกล้ฉัน”

“ความรู้สึก... เป็นเพียงความผันผวนของระดับสารสื่อประสาทและปฏิกิริยาเคมีชั่วคราวที่ไม่เสถียรในสมอง” ธันย์เอ่ยเสียงสั่นแผ่วเบา เกราะตรรกะที่เคยใช้ควบคุมตนเองบัดนี้สลายลงช้าๆ เมื่อฝ่ามืออันอบอุ่นและนุ่มนวลของนิ้งแนบสนิทอยู่ข้างแก้มของเขา

“งั้นปล่อยให้เคมีชิ้นนี้มันผันผวนอย่างไร้เสถียรภาพดูสักครั้งสิคะ...” นิ้งสบตาเขา แววตาสั่นไหวเปี่ยมล้นไปด้วยอารมณ์รักและแรงท้าทาย “...คนเนี้ยบระดับท็อป 1% อย่างคุณ จะกล้าเสี่ยงทำเรื่องนอกระบบบ้างไหม?”

ธันย์จ้องสบดวงตากลมโตและริมฝีปากอิ่มของหญิงสาวตรงหน้า นัยน์ตาของเขาประกายกล้า เกราะตรรกะที่ใช้บดบังหัวใจพังพินาศลงในเสี้ยววินาที

เขารู้ดีว่านี่คือกับดักทางอารมณ์และแผนการยั่วเย้า... แต่เป็นกับดักเพียงหนึ่งเดียวที่เขาเต็มใจก้าวลงไปเล่นเอง

ธันย์เลิกยกคำคำนวณความเสี่ยง เขาขยับแขนแกร่งรวบกอดเอวบางของนิ้ง ดึงร่างอุ่นกระชับเข้ามาชิดแนบอกกว้างอย่างไร้ระยะห่าง นัยน์ตาคมเข้มฉายประกายหนักแน่นและแสนเสน่หา

“ในสมองผมรายงานว่าความเสี่ยงของการกระทำนอกระบบนี้คือ 100%...” ธันย์เอ่ยกระซิบข้างหูเธอด้วยโทนเสียงนิ่งต่ำทว่าสะกดลมหายใจ “...แต่ผมยินดีรับความเสียหายทางระบบทั้งหมด”

ธันย์ก้มใบหน้าลงประทับจูบแน่นหนักและลึกซึ้งบนริมฝีปากอิ่มของนิ้งทันที!

รสสัมผัสหอมหวานละมุนตัดสลับกับไอหนาวเย็นยะเยียบของสเปซหิมะภายนอกเรือนกระจก นิ้งสะดุ้งชะงักไปเล็กน้อยด้วยความตกใจที่สถาปนิกมาดนิ่งตอบสนองรวดเร็วและรุกคืบหนักขนาดนี้ แต่เพียงวินาทีถัดมา เธอก็เอื้อมวงแขนเรียวโอบกระชับรอบคอแกร่งของเขา ตอบรับและบดจูบนั้นคืนด้วยความโหยหาและความรู้สึกรักที่แบกรับสะสมมาตลอดสามปีเต็ม

เสียงพายุม่านหิมะด้านนอกบ้านกระจกพัดกระโหมกระหน่ำอย่างรุนแรง แต่ภายในสเปซจำลองกลับเต็มไปด้วยกระแสความอบอุ่นและอัตราการเต้นของหัวใจที่เต้นเป็นจังหวะประสานกัน (Coherent HRV) และระดับความร้อนชีพจรที่พุ่งขึ้นกระตุ้นให้เซิร์ฟเวอร์ด้านนอกกะพริบแจ้งเตือนสีชมพูสลักแสงวาววับ!

กุญแจถอดรหัสชีวภาพที่เชื่อมสัญญารักแท้เหนี่ยวนำให้ระบบปลดล็อกม่านกั้นนิรภัยออกโดยอัตโนมัติ! หน้าจอโฮโลแกรมสีกราไฟต์คลี่ตัวแผ่ออก เผยรหัส Root File ความทรงจำชั้นลึกสุดที่แอบซ่อนอยู่ใต้จิตใต้สำนึกของนิ้ง

ธันย์ค่อยๆ ถอนจูบออกอย่างอ้อยอิ่งช้าๆ สบประสานดวงตากับใบหน้าเนียนที่ซับสีระเรื่อของนิ้งด้วยแววตาอ่อนโยนแสนเสน่หาที่ไร้หน้ากากตรรกะมาบดบัง

“ปลดรหัสระบบเรียบร้อย...” ธันย์เอ่ยเสียงต่ำ ปลายนิ้วสัมผัสเกลี่ยไรผมข้างแก้มเธอเบาๆ “...และเกมนี้ คุณแพ้แล้ว นิ้ง”

นิ้งยิ้มหวานทั้งที่หัวใจยังเต้นระทึกไม่หาย “ฉันแพ้ตรงไหนคะ?”

“คุณแพ้ตรงที่...” ธันย์สบตาเธอลึกซึ้ง “...คุณป้อนข้อมูลเขียนทับให้สถาปนิกคนนี้ ลืมวิธีการคิดแบบมินิมอลไปจนหมดสิ้นแล้ว”

หลังการเชื่อมต่อสิ้นสุดลง นิ้งหลับใหลลงด้วยความอ่อนล้าสะสมบนเตียงวิเคราะห์

ธันย์ยืนจ้องมองรหัสชุดคำสั่ง Root File ที่เพิ่งดึงออกมาจากหัวนิ้งบนแผงควบคุมหลักของเมนเฟรม แสงสีเงินและสเปกตรัมประสาทกะพริบตัวประมวลผลดึงไฟล์บันทึกความจำออกมาเป็นภาพโฮโลแกรมประวัติศาสตร์สามมิติ ปอนด์เดินก้าวเข้ามาในห้องวิจัย ยืนขมวดคิ้วแน่นมองภาพที่ฉาย

“ไอ้ธันย์... ถอดรหัส Root File ชั้นในสุดได้แล้วเหรอวะ? ไหนขอดูหน่อยว่ายัยตัวป่วนซ่อนความจำอะไรไว้”

ธันย์กดรันปุ่มดึงข้อมูลขั้นสุดท้าย... และทันทีที่ภาพจำลองเวลา เส้นสายประสาท และวันเวลาในความทรงจำ 3 ปีถูกคลี่คลายออกทั้งหมด...

ใบหน้าของธันย์กลับซีดเผือดลงอย่างฉับพลัน! ร่างกายของเขานิ่งแข็งดั่งหินสลัก!

ปอนด์อ้าปากค้าง ถ้วยกาแฟในมือร่วงหล่นลงพื้นเสียงดังโครม “เชี่ย... ไอ้ธันย์... นี่มัน...”

ไฟล์ Root File ความทรงจำที่แท้จริงในหัวของนิ้ง... ไม่เคยมีเรื่องราวของ ‘ภีม’ หรือ ‘คนรักในอดีตที่เป็นคนอื่น’ เลยแม้แต่เซกเมนต์เดียว!

ความทรงจำระยะเวลา 3 ปี 2 เดือน 14 วันที่เธอต้องการลบล้าง... แท้จริงแล้วคือ ความทรงจำเกี่ยวกับการใช้ชีวิตร่วมกัน และความรักระหว่างเธอกับ **‘ตัวธันย์เอง’** ในฐานะคู่รักและผู้ร่วมก่อตั้งโปรเจกต์ ECHO LAB รุ่นแรก!

และรหัสสั่งลบความจำซ้อน 3 ครั้งในหัวของนิ้งที่ธันย์สแกนเจอในบทแรก... ไม่ใช่เกิดจากการที่ธันย์ไปสั่งลบความจำของนิ้ง

แต่คือ... **ตัวธันย์เองที่ยอมเขียนโค้ด Pre-authorized signature ทิ้งไว้ และสั่งให้นิ้งช่วยกดปุ่มดำเนินการลบความทรงจำในหัวของตัวธันย์เองถึงสามครั้ง** เพื่อสร้าง plausible deniability ปกป้องนิ้งจากคดีฟ้องร้องจริยธรรมที่ภีมจัดฉากแบล็กเมล์เมื่อสามปีก่อน!

คนที่สมองว่างเปล่า ถูกลบความทรงจำ และโดนสวมบทบาทคนแปลกหน้ามาตลอดสามปีเต็ม... ไม่ใช่นิ้ง... แต่คือตัวของธันย์เอง!
