# THE ECHO — บทที่ 7: กระดานเปล่า

**[ECHO ARCHITECTURE LAB – 08:30 น.]**

แสงแดดจัดจ้ายามเช้าของวันขีดเส้นตาย ส่องลอดผ่านมู่ลี่อะลูมิเนียมตรงแนวยาวของห้องทำงานประธาน

เงาของเส้นสายตรงกริบสีเทาเข้มตัดผ่านโต๊ะทำงานสแตนเลสและใบหน้าเรียบตึงไร้อารมณ์ของธันย์ ธันย์นั่งพิงเก้าอี้ทำงานสไตล์มินิมอลอยู่เพียงลำพัง ดวงตาคมกริบจ้องมองจอโฮโลแกรมสแกนข้อมูลระบบประสาทของนิ้งที่ลอยอยู่ตรงหน้า แววตาของเขาปราศจากร่องรอยของการพักผ่อนตลอดทั้งคืน สมองประมวลผลคำนวณและปะติดปะต่อความจริงย้อนหลัง 3 ปีทีละส่วนอย่างเป็นระบบ

*ความจริงที่ว่า... เขาคือคนที่ลบความทรงจำของตัวเองทิ้ง และทำเป็นคนแปลกหน้าใส่เธอมาตลอดสามปี*

*ติ๊ด...*

เสียงระบบสแกนประตูเลื่อนเปิดออกช้าๆ นิ้งเดินก้าวเข้ามาในห้องทำงานด้วยสรีระที่สง่างามในชุดเสื้อเชิ้ตแขนยาวสีพาสเทลกับกางเกงสแล็กสีเบจเรียบร้อย ใบหน้าเนียนสดใส รอยยิ้มแสนกวนปั้นหัวประดับมุมปากเช่นเคย

“อรุณสวัสดิ์ค่ะ คุณผู้อำนวยการ” นิ้งเอ่ยทักทายเสียงใส “ผลการถอดรหัส Root File เมื่อคืนเสร็จสิ้นไหมคะ? คุณลบ ‘ขยะความทรงจำแฟนเก่าพันล้าน’ ออกไปจากสมองฉันเรียบร้อยหรือยัง?”

ธันย์ค่อยๆ ช้อนนัยน์ตาขึ้นมองเธอช้าๆ แววตาของเขานิ่งสงบ เย็นชาดั่งผิวน้ำแข็งที่ไร้กระแสลมปะทะ... มันนิ่งและเงียบงันจนสัญชาตญาณของนิ้งจับรอยผิดปกติได้ รอยยิ้มมุมปากของเธอเจื่อนวูบลงชั่วขณะ เธอชะงักก้าวเดินระยะสามก้าวหน้าโต๊ะสแตนเลส

“กระบวนการแยกส่วนข้อมูลเสร็จสิ้นสมบูรณ์” ธันย์ตอบกลับเสียงเรียบนิ่ง ไร้โทนอารมณ์ “ไฟล์ความทรงจำที่ระบุข้อขัดแย้งเกี่ยวกับ ‘ผู้ชายคนนั้น’ ถูกบีบอัดและเขียนทับด้วยระบบความปลอดภัยเป็นที่เรียบร้อย”

นิ้งพยักหน้ารับช้าๆ ขมวดคิ้วเล็กน้อย “งั้น... ฉันก็ไม่มีความเสี่ยงเรื่องข้อมูลรั่วไหลแล้วใช่ไหมคะ?”

“ไม่มีครับ” ธันย์ยกมือปัดปิดหน้าจอโฮโลแกรมลงตรงหน้า เหลือเพียงความกว้างขวางของโต๊ะสแตนเลสที่โล่งว่าง “ตามข้อกำหนดในสัญญาจ้าง เคสจดทะเบียนจูนสมองของคุณสิ้นสุดลงสมบูรณ์ คุณสามารถลงลายมือชื่อดิจิทัลปิดงาน แล้วเดินออกไปจาก ECHO LAB ได้ทันที”

นิ้งจ้องมองธันย์นิ่ง ความเงียบโรยตัวเข้าบีบกั้นพื้นที่ระหว่างคนทั้งสอง นิ้งขบเม้มริมฝีปากลึก สับสนในใจอย่างเห็นได้ชัด

*สัมผัสอบอุ่นและจูบจริงใจท่ามกลางพายุม่านหิมะจำลองเมื่อคืน... มลายหายไปหมดแล้วหรือ? ทำไมสถาปนิกหน้านิ่งคนนี้ถึงกลับมาสวมมาดหุ่นยนต์เย็นชาไร้หัวใจใส่เธออีกครั้ง? หรือกระบวนการกู้คืน Root File เมื่อคืนมันส่งมัลแวร์ทำลายความรู้สึกของเขาไปจนหมดจด?*

“คุณ... ไม่มีประเด็นอะไรจะสอบถามฉันต่อเลยเหรอคะ?” นิ้งเอ่ยถามเสียงแผ่ว “เช่น... อาการทางกายภาพหลังแยกไฟล์ หรือความทรงจำที่หายไป?”

“การสอบถามความรู้สึกหลังรันระบบจูนประสาท... ถือเป็นเรื่องที่ไร้หลักตรรกะทางวิศวกรรม” ธันย์สบสายตาเธอนิ่งอย่างไร้แววตาตอบรับ “หน้าที่ของผมคือจัดระบบสถาปัตยกรรมสมอง เมื่อซอฟต์แวร์ทำงานสำเร็จ ถือว่าปิดภารกิจ”

นิ้งกำหมัดแน่นข้างลำตัว นัยน์ตาสุดป่วนฉายแววตัดพ้อ เจ็บปวด และสับสนอย่างหนักหน่วงที่สุดในรอบสามปี เป็นครั้งแรกที่ผู้บงการสาวผู้วางหมากป่วนหัวใจเขามาตลอด รู้สึกว่าตัวเองกำลังสูญเสียการควบคุมและเสียเขาไปตลอดกาลจริงๆ

“เข้าใจแล้วค่ะ” นิ้งตอบรับเสียงเย็น กางแผงหน้ารับใบตรวจงาน เลื่อนลงลายมือชื่อดิจิทัลอย่างรวดเร็วโดยไม่ปรายตามองสบตาเขาอีกเลย เมื่อลงชื่อเสร็จ เธอหมุนกายหยิบกระเป๋าถือ เตรียมก้าวเท้าเดินออกจากห้องทำงานมินิมอลแห่งนี้ไปให้พ้นสายตาของเขา

ทว่า... ก่อนที่ปลายเท้าบูตหนังสีเบจของเธอจะพ้นขอบประตู

“นิชาภา” ธันย์เอ่ยเรียกชื่อจริงเธอเสียงเรียบ

นิ้งหยุดก้าวเดิน แผ่นหลังของเธอเหยียดตึง แต่เธอไม่ได้หมุนตัวกลับมามอง “คะ?”

“ถุงกาแฟเอสเพรสโซคั่วเข้มแบรนด์นอกที่คุณนำมาให้ผมเมื่อคืน...” ธันย์เอ่ยช้าๆ น้ำเสียงแฝงการรุกต้อนสะกดอารมณ์ “ผมตรวจสอบคลังวัตถุดิบย้อนหลังแล้ว... ECHO LAB ไม่เคยมีนโยบายสั่งกาแฟแบรนด์นี้เข้ามาในแล็บ และผม... ก็ไม่เคยพิมพ์บอกใครลงเซิร์ฟเวอร์ว่าผมชอบดื่มมันยามดึก”

นิ้งนิ่งอึ้งไป หัวใจเต้นกระตุกรัวในอก

“และกำไลข้อมือสีกราไฟต์ที่คุณใส่...” ธันย์ลุกขึ้นยืนช้าๆ ร่างสูงสง่าเดินลุยความเงียบก้าวเดินมาหยุดยืนอยู่ทางเบื้องหลังของเธอในระยะห่างเพียงหนึ่งก้าว “...รหัสผ่านเข้าควบคุมเซิร์ฟเวอร์ชั้นล่างสุดของผม เป็นตัวเลขวันเกิดของคุณกับผมผสมกัน ซึ่งถูกตั้งล็อกไว้ในระบบตั้งแต่เมื่อสามปีก่อน”

นิ้งค่อยๆ หมุนตัวกลับมามองสบตาเขาอย่างช้าๆ นัยน์ตาคู่สวยสั่นไหวระริกด้วยความรู้สึกท่วมท้นเมื่อเห็นว่า แววตาของธันย์บัดนี้ไม่ได้เฉยชาหรือว่างเปล่าอีกต่อไป... แต่กลับฉายประกายแวววาวประกายความลึกซึ้ง ความรู้ทัน และความเสน่หาอย่างเหนือชั้น!

“ตัวเลขวันเกิดของคุณที่ผมเพิ่งค้นเจอจากการเปิดดูข้อมูล Root File ของคุณเมื่อคืน... มันช่วยอธิบายว่าทำไมผมถึงใช้รหัสผสมนั้นกับระบบของผมมาตลอดสามปีโดยหาเหตุผลไม่ได้”

ธันย์ยื่นมือขวาไปคว้าประคองข้อมือซ้ายของนิ้งไว้เบาๆ นิ้วเรียวสัมผัสบนกำไลกราไฟต์อุ่น แล้วขยับเคาะปลายนิ้วลงบนหลังมือของเธอเป็นรหัสตอบรับ 3 จังหวะสะกิด **(3-Beat Confirm Code)** แบบเดียวกับที่เธอเคยปั่นหัวเขาเมื่อวันก่อน

“เกมกระดานเปล่า (Blank Slate) ที่คุณพยายามจะแกล้งทำเป็นปิดเคสเดินจากไปเพื่อให้ผมคิดว่าเราไม่มีประวัติศาสตร์ร่วมกัน...” ธันย์ก้มลงกระซิบแผ่วเบาข้างหูเธอ เสียงนิ่งต่ำทว่าหนักแน่นสะเทือนหัวใจ “...มันใช้ไม่ได้ผลกับสถาปนิกที่เพิ่งจะเจาะ Root Code ในสมองคุณสำเร็จเมื่อคืนนี้หรอกนะ นิ้ง”

นิ้งอ้าปากค้างเล็กน้อย ดวงตาเต็มไปด้วยความตระหนกและยินดีปะปนจนแทบเอ่ยเสียงไม่ออก

“คุณ... คุณกู้ข้อมูลรหัสผ่าน Root File ได้สำเร็จจริงๆ แล้วเหรอ?!”

ธันย์จุดยิ้มที่มุมปาก ยิ้มที่กริบเกลียดและแฝงความรักความคลั่งไคล้สูงสุดอย่างไร้เกราะบดบัง

“ใช่ครับ... และตอนนี้ ได้เวลาที่คุณต้องสารภาพความจริงทั้งหมดเกี่ยวกับกลยุทธ์ ‘การลบความทรงจำสามครั้ง’ ของคุณกับผมแล้ว นิชาภา”
