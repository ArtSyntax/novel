# THE ECHO — บทที่ 2: รหัสซ้อน

**[ECHO ARCHITECTURE LAB – NEURAL SIMULATION CHAMBER – 11:15 น.]**

ห้องจำลองสถาปัตยกรรมประสาทตั้งอยู่ลึกลงไปในชั้นใต้ดินของแล็บ ซึ่งถูกหุ้มด้วยฉนวนกันคลื่นแม่เหล็กไฟฟ้าอย่างหนาแน่นเพื่อสร้างความบริสุทธิ์ทางสัญญาณ

ผนังห้องทรงโดมครึ่งวงกลมบุด้วยแผ่นซับคลื่นแม่เหล็กไฟฟ้าสีดำสนิท ไร้เหลี่ยมมุมและรอยตัดเย็บประหนึ่งห้องนิรภัยที่ลอยอยู่ในความว่างเปล่า มีเพียงเตียงปรับระดับกึ่งนั่งกึ่งนอนทำจากอะลูมิเนียมเกรดการบินตั้งอยู่ตรงกลาง แสงไฟ LED สีไอซ์บลู (Ice Blue) เรืองแสงจางๆ ออกมาจากขอบพื้นผิวโลหะ สร้างบรรยากาศเย็นเยือกและสว่างเพียงพอสำหรับผู้คุมสภาวะ

นิ้งนอนราบอยู่บนเตียงจำลอง เส้นผมยาวของเธอแผ่กระจายบนหนุนอะลูมิเนียมอ่อนนุ่ม อุปกรณ์เหนี่ยวนำประสาทไร้สัมผัส (Non-invasive Neural Pods) จำนวนแปดจุดลอยตัวนิ่งเหนือขมับและท้ายทอยของเธอ มันกะพริบแสงสีส้มบางเบาขณะส่งผ่านคลื่นแม่เหล็กความถี่ต่ำเพื่อปรับจูนเชื่อมต่อสัญญาณประสาทเข้ากับเครื่องประมวลผลเซิร์ฟเวอร์หลักของ ECHO LAB

ธันย์ยืนจัดระเบียบข้อมูลอยู่หลังแผงควบคุมสแตนเลสปัดเงาข้างเตียง สวมเสื้อกาวน์สั้นสีเทาเข้มตัดเย็บเฉียบคม นิ้วยาวเรียวของเขากดคีย์รันชุดคำสั่งทดสอบระบบอย่างช้าๆ สายตาคมกริบวิเคราะห์ตัวแปรทางชีวภาพ (Biometric Variables) บนหน้าจอโฮโลแกรมด้วยสมาธิขั้นสูง

“อัตราการเต้นของหัวใจ 68 ครั้งต่อนาที ความดันปกติ คลื่นสมองเบต้าสงบผิดปกติสำหรับคนที่กำลังจะถูกเจาะลึกจิตใต้สำนึก” ธันย์เอ่ยขึ้น น้ำเสียงเรียบต่ำโดยไม่หันไปมองหน้า “คุณแน่ใจนะว่าไม่ได้ทานยาสงบประสาทหรือคลายกังวลมาก่อนรันระบบ?”

นิ้งที่นอนหลับตานิ่งๆ จุดรอยยิ้มมุมปาก “ฉันแค่ตื่นเต้นค่ะ... ตื่นเต้นที่จะได้เห็นว่าคุณสถาปนิกหน้านิ่งเวลาต้อนคนอื่นอยู่ในหัวจำลอง จะมีอาการหลุดฟอร์มเชิงเทคนิคบ้างไหม”

“ในสเปซจำลองประสาท ผมทำงานในฐานะ ‘ผู้สังเกตการณ์’ (Observer) เท่านั้น” ธันย์ตอบกลับด้วยเสียงเฉยเมย “ผมจะโปร่งแสง ไม่มีตัวตนทางอารมณ์ และไม่ถูกผลกระทบจากสิ่งเร้าใดๆ ในสมองของคุณ หน้าที่ของผมคือการวิเคราะห์หาข้อมูลแปลกปลอม รหัส Root ที่ล็อกไว้ แล้วตัดการเชื่อมต่อมันออกอย่างเป็นระบบ ส่วนอารมณ์ที่ผันผวนของคุณ... คุณต้องจัดการมันด้วยตัวเอง”

“ค่ะๆ รับทราบกฎข้อกำหนดค่ะ คุณผู้สังเกตการณ์ไร้หัวใจ” นิ้งหัวเราะเบาๆ ในลำคอ

ธันย์มองตัวเลขชีวภาพของเธอบนจออีกครั้ง ก่อนจะยกมือขวาขยับสั่งการคำสั่งเข้าระบบ

*วิ้งงงงง—*

คลื่นความถี่ต่ำส่งเสียงกังวานแผ่วเบาในอากาศ อุปกรณ์ Neural Pods สลักแสงวงแหวนหมุนรอบศีรษะของนิ้งช้าๆ ก่อนที่ระดับสติสัมปชัญญะของทั้งสองคนจะถูกดึงและบีบอัดจมดิ่งเข้าสู่โลกเสมือนจริงในเสี้ยววินาที

**[SIMULATION SPACE – THE FIRST MEMORY]**

สัมผัสแรกที่กระทบประสาทรับรู้ของธันย์เมื่อลืมตาขึ้นในสเปซประสาทเสมือน คือกลิ่นอายอุ่นของฝนตกใหม่ๆ ผสมผสานกับกลิ่นเมล็ดกาแฟเอสเพรสโซคั่วเข้มข้นที่ลอยอวลในอากาศ

ทิวทัศน์รอบตัวแปรเปลี่ยนจากห้องโดมดำสนิทกลายเป็นร้านกาแฟเรือนกระจกสไตล์กลาสฮาวส์ (Glasshouse) ล้อมรอบด้วยสวนไม้ใบเขียวชอุ่มยามเย็น หยดน้ำฝนเกาะแพรวพราวบนกระจกบานยาว แสงแดดสีส้มอบอุ่นของพระอาทิตย์ตกดินทอดลำแสงเฉียงตัดผ่านห้องอย่างมีมิติ ทั้งอุณหภูมิ ความชื้น และบรรยากาศสมจริงเสียจนผิวหนังจำลองของธันย์ตอบสนองต่อลมเย็นจากเครื่องปรับอากาศภายในร้าน

ธันย์ยืนอยู่กลางร้านในฐานะร่างโปร่งแสงสีเงินที่คนในความทรงจำมองไม่เห็น เขากวาดสายตามองไปรอบๆ อย่างวิเคราะห์

ตรงโต๊ะไม้โอ๊กริมกระจก นิ้งในอดีตกำลังส่งรอยยิ้มสดใสให้ชายหนุ่มใบหน้าเนี้ยบสวมสูทสากลแบรนด์เนมที่นั่งฝั่งตรงข้าม—‘ภีม’ ประธานแห่ง Aetheris Capital ในช่วงวัยที่ยังดูหนุ่มกว่าปัจจุบันเล็กน้อย

*ภีม... แฟนเก่าพันล้านอย่างนั้นหรือ?*

ธันย์ขมวดคิ้วลึก เขาก้าวเดินเข้าไปชิดขอบโต๊ะ ยกมือชูแผงควบคุมระบบ (Code Inspector) กลางอากาศเพื่อสแกนโครงสร้างอัลกอริทึมของความทรงจำฉากนี้ แต่ทันทีที่ปลายนิ้วสัมผัสรหัสสัญญาณ รังสีแจ้งเตือนสีแดงเข้มก็สว่างวาบขึ้นบนแผงข้อมูลส่วนตัว

[WARNING: RECURSIVE LOOP DETECTED]
[DATA MISMATCH: MEMORY INFRASTRUCTURE IS ARTIFICIAL]

ธันย์ชะงัก สายตาหันขวับกลับไปจ้องมอง ‘นิ้งในความทรงจำ’ ที่กำลังยิ้มหวานส่งให้ภีม...

ทันใดนั้น นิ้งที่ควรจะเป็นเพียงภาพจำย้อนหลัง กลับค่อยๆ หันหน้ากลับมามองสบตากับธันย์โดยตรง! ทั้งที่เขาอยู่ในสถานะผู้สังเกตการณ์โปร่งแสงที่ระบบต้องซ่อนตัวตนไว้ รอยยิ้มอ่อนหวานของเธอเปลี่ยนเป็นรอยยิ้มกวนประสาทและแสนเจ้าเล่ห์

“ไงคะ... ตกหลุมพรางไวไปไหม คุณสถาปนิก?”

เสียงของนิ้งดังขึ้นจากเบื้องหลังของธันย์!

ธันย์หันตัวกลับไปอย่างรวดเร็ว มองเห็น ‘นิ้งตัวจริง’ ในสเปซจำลอง ยืนกอดอกพิงเสาเหล็กสีดำข้างๆ เขา เธอสวมชุดสูทสั้นสีเบจตัวเดิม และจ้องมองเขาด้วยแววตาของผู้ชนะ

“นี่คือไฟล์ความทรงจำซ้อน (Recursive Memory Trap)” ธันย์พูดเสียงต่ำลงและเต็มไปด้วยความระมัดระวัง “คุณไม่ได้รันไฟล์จำลองความทรงจำในอดีต... แต่คุณกำลังสร้างฉากปลอมขึ้นมาสดๆ เพื่อทดสอบว่าระบบความปลอดภัยของผมจะตรวจพบความผิดปกติได้เร็วแค่ไหน”

“สิบสี่วินาทีค่ะ” นิ้งยกนาฬิกาข้อมือขึ้นดูแล้วหัวเราะเสียงใส “ถือว่าระบบประมวลผลเร็วสมฐานะ... คุณรู้ทันว่าภีมไม่ใช่แฟนเก่าฉัน และกลาสฮาวส์คาเฟ่นี่เป็นแค่เรื่องโกหก”

“เล่นเป็นเด็ก” ธันย์จ้องมองเธอด้วยนัยน์ตาเย็นชา “การจงใจฉีดข้อมูลเท็จข้ามผ่านระบบประมวลผลประสาท อาจทำให้สมองคุณเกิดภาวะ Remapping ผิดรูปรุนแรง มันคือการกระทำที่ไร้ตรรกะและเสี่ยงอันตรายเกินไปสำหรับตัวคุณเอง”

“แต่ถ้าฉันไม่ลองใช้วิธีนี้... ฉันจะรู้ได้ยังไงล่ะคะว่าคุณมีความสามารถพอจะถอดรหัส ‘ของจริง’ ที่ล็อกไว้ลึกสุดขั้วในสมองฉัน?” นิ้งก้าวเท้าเดินเข้าหาธันย์ทีละก้าว นัยน์ตาสีน้ำตาลเข้มของเธอเต็มไปด้วยแรงขับท้าทาย “หรือว่า... สถาปนิกหน้านิ่งคนนี้กำลังเริ่มกลัวขึ้นมาแล้วคะ?”

ธันย์ไม่ขยับหนี เขายืนนิ่งบดบังระยะห่าง ปลายจมูกของทั้งคู่เกือบชิดกัน นัยน์ตาของเขาประกายวับและจุดรอยยิ้มที่มุมปากเพียงเล็กน้อย—ยิ้มที่แทบไม่เคยมีใครได้เห็นจากชายไร้อารมณ์คนนี้ มันคือรอยยิ้มของนักยุทธศาสตร์ที่เห็นหมากฝ่ายตรงข้ามเปิดช่องโหว่

“คุณคิดว่าคุณเป็นเจ้าของและเป็นคนคุมสเปซนี้จริงๆ เหรอ นิชาภา?”

ธันย์ยกมือขวาขึ้นมา แล้วสะบัดนิ้วเบาๆ เพียงครั้งเดียว

*พรึบ!*

โครงสร้างร้านกระจกกลาสฮาวส์ สวนด้านนอก หยดน้ำฝนจำลอง และภาพร่างจำลองของภีม ทลายสลายหายวับกลายเป็นฝุ่นละอองสีเงินในพริบตา! โลกเสมือนรอบตัวถูกเขียนทับ (Overwrite) อย่างเฉียบพลัน กลายเป็นเพนท์เฮาส์สไตล์ Modern Minimalist ขนาดกว้างขวาง คุมโทนสีโมโนโทนเงียบสงัด มองเห็นวิวแสงไฟของเมืองใหญ่ยามค่ำคืนผ่านผนังกระจกบานโต

นิ้งเหวอและเซถอยหลังไปครึ่งก้าวเมื่อพื้นที่จำลองที่เธอพยายามครอบครองสิทธิ์การรันระบบ ถูกยึดอำนาจการควบคุม (Root Override) ไปอย่างสมบูรณ์แบบ

“ในระบบประสาทของคุณ คุณอาจจะแอบใส่ไฟล์ปลอมเข้ามา” ธันย์ก้าวเดินต้อนความกว้างขวาง ย่างสามขุมเข้าหานิ้ง บีบระยะห่างจนอกหนาเกือบชนกับร่างบางของเธอ “แต่ในเซิร์ฟเวอร์จำลองของ ECHO LAB... ผมคือระบบปฏิบัติการสูงสุด (OS) ผมสามารถเขียนทับโครงสร้างอารมณ์ของคุณได้ทุกเมื่อที่คุณเล่นนอกบทบาท”

นิ้งเชิดหน้าขึ้น สบตาเขาในระยะประชิด แม้จะเสียเปรียบด้านสิทธิ์ระบบ แต่เธอก็ยังไม่ยอมจำนน

“เขียนทับเหรอคะ?” นิ้งกระซิบเสียงกวนประสาท ยื่นหน้าเข้าใกล้จนสัมผัสลมหายใจอุ่น “งั้นลองเขียนทับความรู้สึกที่ว่า... หัวใจของคุณกำลังเต้นรัวเพราะได้อยู่ใกล้ฉันตรงนี้ให้ดูหน่อยสิคะ คุณสถาปนิก”

ธันย์จ้องลึกเข้าไปในดวงตาของเธอ นิ่งเงียบ ระบบประสาทส่วนลึกของเขาตอบสนองเฉียบพลัน คอนแทกต์เลนส์สแกนเนอร์ส่งข้อมูลส่วนตัวแจ้งเตือนว่า **อัตราการเต้นของหัวใจเขาพุ่งขึ้น 12 ครั้งต่อนาที (bpm) จากค่าเฉลี่ยปกติ และช่วงห่างระหว่างการเต้นของหัวใจ (R-R Interval) หดสั้นลงอย่างมีนัยสำคัญ**

แต่เขาไม่ปล่อยให้อัตราความผิดเพี้ยนนี้มาทำลายกระดานหมากของเขา

ธันย์ยื่นมือขวาไปคว้าจับข้อมือของนิ้งไว้อย่างนุ่มนวลทว่าหนักแน่น นิ้วเรียวแตะนิ่งตรงจุดชีพจรใต้กำไลกราไฟต์ สายตาคมกริบของเขามองไล่ระดับลงมาจากดวงตากลมโต มาหยุดอยู่ที่ริมฝีปากอิ่มของเธอชั่วครู่ ก่อนจะเอ่ยเสียงนิ่งต่ำทว่าสะกดคนฟัง

“อัตราการเต้นของหัวใจคุณพุ่งขึ้นเป็น 89 ครั้งต่อนาที... คุณเองต่างหากที่กำลังหลงกลฉากจำลองที่ผมเขียนขึ้น นิ้ง”

นิ้งชะงักไป ดวงตาแพรวพราวฉายประกายสับสนและพ่ายแพ้ชั่วคราวเมื่อโดนย้อนกลับด้วยข้อเท็จจริงชีวภาพที่ปฏิเสธไม่ได้!

“กระดานนี้... ผมชนะ” ธันย์ใช้นิ้วชี้มือซ้ายแตะลงบนขมับของเธอเบาๆ “และตอนนี้... รันไฟล์ความทรงจำจริงของคุณออกมาได้แล้ว ก่อนที่ผมจะสั่งตัดการเชื่อมต่อแบบฉุกเฉิน (Force Shutdown) แล้วปล่อยให้คุณตื่นขึ้นมาพร้อมกับอาการปวดหัวรุนแรงไปอีกสามวัน”
